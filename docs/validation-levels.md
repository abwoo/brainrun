# BrainRun 验证层次：数值正确性 vs 生理真实性

版本：v1.0（PR1）。依据：审查报告 `docs/review-2026-11-11.md` §六；
本文件把验收分成两个独立维度。**通过其中一个，绝不等于通过另一个。**

## 维度一：数值正确性

**定义**：程序是否正确执行了既定的数学模型（Wilson–Cowan 方程、
Heun 积分、延迟耦合、刺激事件）。只回答“算得对不对”，
不回答“算出来的东西像不像真的大脑”。

### 当前状态

| 检查项 | 结果 | 证据 |
|---|---|---|
| Python 参考实现 vs Rust 引擎 | 六场景最大偏差 3.33e-16（机器精度） | `docs/validation.md` §2、`reference/python-model/compare.py` |
| 步长收敛 | dt=1 ms 相对 dt=0.5 ms 最大偏差 6.3e-04；dt=2 ms 时 3.1e-03；二阶收敛 | `docs/validation.md` §2 |
| 确定性 / 可重复 | 相同初值与事件序列重复产生相同结果；`noise_amp=0` 时 RNG 不使用 | `docs/model-spec.md` §8.5 |
| 固定点与稳定性 | A-set 三不动点（E\*=0.073 稳定、0.127 不稳定、0.475 稳定）已用 scipy 验证；演示预设唯一稳定点 E\*=0.011 | `docs/validation.md` §1 |
| 因果性 | G=0 时被刺激脑区 ΔE≈0.483，其余 75 脑区 ΔE=0 | `docs/acceptance.md` |
| 与 TVB 官方实现对照 | **已完成（PR1）**：演示预设下最大偏差 max\|ΔE\| ≤ 2.49e-04（刺激场景，2000 ms），自由运行 7.46e-05；A-set 下 2.73e-02 只出现在双稳态翻转的瞬态爬升段，终态一致（差 1.4e-10）。唯一系统性差异来源已因果证实：TVB 在 Heun 校正步冻结延迟耦合，本引擎在校正步用一步更新的延迟耦合；把本引擎改成冻结耦合后与 TVB 的偏差降到 1.4e-08。详见 `docs/tvb-crosscheck.md`，脚本 `reference/tvb-crosscheck/crosscheck.py`（tvb-library 2.10.0） | `docs/tvb-crosscheck.md`、`reference/tvb-crosscheck/outputs/crosscheck.json` |

### 缺口

- TVB 官方对照尚未完成前，“与 TVB 官方实现一致”这一项不得打勾。
- 未做长时间（>10 分钟）连续运行的数值漂移检查（PR5 真机验收时补）。

## 维度二：生理真实性

**定义**：模型行为与真实神经活动数据的吻合程度。只回答“像不像真的大脑”，
不回答“算得对不对”。本维度目前**基本缺失**，以下逐项如实列出。

### 当前状态

| 检查项 | 结果 | 说明 |
|---|---|---|
| 连接组与真实人脑的对应 | **不成立** | 默认连接组是 Demo Connectome：猕猴 CoCoMac + 人类 DSI 混合矩阵，皮层下结构未包含；TVB 官方声明其生物物理真实性有限（见 `docs/model-spec.md` §1、应用内「模型信息」） |
| 模型与真实神经活动的对照 | **未做** | 没有用任何真实记录的神经活动数据（EEG / MEG / fMRI / 电生理）约束或检验过模型行为 |
| 刺激响应的生理量级 | **未验证** | 脉冲峰值 ΔE≈0.48 是模型单位下的数值，未映射到任何可测量的生理量 |
| 频率 / 振荡特征 | **未验证** | 未与真实脑电节律（如 alpha、theta）做过谱对照 |
| 参数的生理依据 | **部分** | A-set 参数来自 TVB 代码默认值（与 Sanz-Leon et al. 2015 表 11a 一致），演示预设 θ_e=1.0 是为“点击—响应—恢复”循环做的产品层选择，不是生理测量值 |

### 缺口（按优先级）

1. 增加经过验证的人类结构连接图谱作为另一种模型选择（审查 PR1 建议，
   本 PR 只完成标注与许可核查，换图谱本身不在 PR1 范围）。
2. 用具有明确物种和条件的真实神经活动数据约束模型行为（需另立验证任务，
   不在本 PR 范围；做之前先定数据来源与对照指标）。
3. 在此之前，任何对外口径不得把数值正确性的通过说成生理真实性的通过。

## 使用规则

- 验收报告（`docs/acceptance.md`）与后续 PR 验收必须分开列出两个维度的结果。
- 新功能若只动了数值正确性（如积分器、对照），不得在生理真实性一栏写“通过”。
- 本文件随验证进展更新；每次更新写清日期与证据链接。
