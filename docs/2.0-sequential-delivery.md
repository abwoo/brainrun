# BrainRun 2.0 sequential delivery
Baseline: 043fc305 (manual physics MVP). The complete specification remains docs/brainrun-2.0-plan.md.

1. Configuration / recording / export consistency: restore active and pending configuration; mark next-run changes; reference transforms carry processing revision; invalidate stale epochs. This change implements this first work package.
2. Native continuous solver acquisition: every 1 ms state is recorded independently of display snapshots; the network EEG action uses a centered 129-tap Hamming FIR and emits 250/500 Hz. Unsupported 64 ms edges on each side are discarded, with event timestamps rebased to the valid signal start. The offline centered filter is not a causal online feedback controller. Necessary gates include SciPy FIR comparison, alias rejection, actual WASM/display-rate invariance and GUI/export checks.
3. Shared physical source state and exported source time courses. Opening signal analysis from the electric workbench records that same source; static sources produce constant voltage. Parameter changes invalidate linked analysis. Dense scalp projections use the same source samples, Raw cursor and recording-channel reference; inverse localization uses that cursor and rejects zero signal. Neural/measurement-noise and independent legacy examples remain explicitly separated.
4. Manual physical interaction: MNE computes an additional 482-vertex scalp lead field; triangle colors interpolate only for rendering. A fixed µV scale drives both surface and sensors. Arrow dragging changes a normalized continuous source vector, polarity reversal changes signed nA.m, clicking a sensor changes the inspected channel, and static-source voltage traces remain constant. These are scalp potentials, not intracranial electric-field vectors.
5. Ready-to-use registered template BEM: lazy-load matching anatomy/forward matrices and full carried FreeSurfer/MNE notices from pinned official MNE archives. Manual sources snap to solved cortex nodes. Shared Raw, topography and inverse dispatch to the BEM matrix; same-coordinate enclosing-sphere comparison is explicitly an approximation. Cloud geometry, fresh MNE, recording and browser gates are required.
6. Physical exploration: electrode drag snaps to 482 MNE-solved scalp vertices and replaces both sensor position and gain row. Two signed sources add linearly. Skull conductivity choices (0.002/0.004/0.008 S/m) load distinct MNE matrices with explicit model IDs. An optional defined 200 ms half-sine input is evaluated directly at every recording sample, with the 500 ms event and shared observation time; it is not a cognitive ERP. Static sources remain flat.
7. Advanced reproducibility: native-feedback features consume every 1 ms E state; evaluation periods, full RMS windows, causal action delay and cooldown use model time. Controller history/pending actions and pending user inputs survive save/restore. Actual Worker replay and display-rate invariance are required gates. PSD/TFR respect source information bandwidth; a resampled 250 Hz grid cannot authorize 40 Hz results from 60 Hz snapshots. Static signals do not receive a fabricated alpha peak.

Each package must pass its necessary numerical checks, frontend build and a focused causal browser check in GitHub before automatic merge. No stage completion substitutes for later physiology or human usability acceptance.

## Delivered software and evidence boundaries

The core physical MVP is source → conductor-specific forward matrix → scalp samples / sensor values / explicitly defined time course → shared Raw → analysis/export. Source orientation, reference, electrode location, second source and tissue choices alter actual computational inputs. The optional template uses MRI/HEAD registration internally; no TVB-to-human registration is inferred.

The live controller supports dimensionless E and an optional physical sensor EEG path. The EEG path freezes the primary source geometry, montage reference and MNE forward coefficient, maps native E/I to an assumed dipole moment, and applies a causal first-order 40 Hz low-pass before instantaneous-magnitude or full-window RMS detection. Worker captures the E/I baseline at activation. The filter state and mapping survive snapshot/restore. Its zero configured delay still schedules action no earlier than the following model ms. The offline centered FIR is not used as a causal controller filter. Independent JR and cell demos remain labeled independent. The separate whole-network A/B path forks the main Worker state explicitly, as described below.

The complete 2.0 research specification remains open for the following evidence/work:

| Requirement | Current boundary | Further acceptance |
| --- | --- | --- |
| Neural activity → physical source calibration | Cell count, synchrony and current-to-moment gains are explicit assumptions | Identifiable parameters and independent human/synthetic reference constraints; no amplitude rescaling presented as validation |
| Multiscale coupling / five physiological rhythm mechanisms / N200–P300–N400 | Numerical local/network models and signal analysis exist | Mechanism-specific independent validation and calibrated interscale coupling |
| Human connectome / atlas transforms | TVB is a mixed demonstration; template HEAD/MRI/MNI305 is explicit | Licensed human connectivity and verified registration; MNI152/true Talairach remain unavailable until validated |

| Novice usability / devices | Cloud browser gestures and narrow-screen layouts only | At least 10 first-time users, 8 completing the core task without help; actual touch and performance trials |
| TVB data rights | Existing unresolved mixed demo-data record retained | Resolve the separate upstream redistribution question |

No new human, real-device or physiological validation was conducted during this implementation. Numerical and browser passes are not those forms of evidence.

## Matched whole-network comparison

The main Rust/WASM network now forks A and B from one complete saved state. A retains G; B changes G only. Both branches carry native 1 ms E/I, controller/input history, restorable end-state JSON and sibling provenance pointing to the same origin run. Identical G must reproduce stochastic trajectories exactly. Original manual snapshots are preserved. After calculation the model returns paused to the origin; branch restore updates main UI parameters. Either retained branch can produce native EEG through the same explicit, unregistered TVB-to-sphere mapping and enter shared analysis/export. Independent JR comparisons remain labeled independent. Optional physical sensor EEG feedback is described below; physiological calibration remains open.

## Remaining-work update: physical EEG feedback

Selected-head-model sensor EEG feedback is implemented with explicit assumed population/current/morphology parameters; it is not physiological calibration or a TVB-to-human anatomical registration. It freezes either the sphere primary source or the selected solved template BEM cortical node, using the same direction, reference, registered electrodes and forward coefficient as that workbench. The independent second manual sphere source is excluded. Its causal online filter is a distinct processing version from offline centered-FIR EEG acquisition. Controller exports retain the frozen measurement geometry, baseline, reference, model ID, units and filter state. Remaining source-calibration, multiscale, rhythm/ERP mechanism, human-connectome/coordinate and human/device requirements above remain open.

## Free electrode combinations

The sphere workbench can select an explicit ordered subset of the current 10–20/10–10/10–05 layout, with a simple six-sensor preset and at least four retained sensors. The standard montage remains identified as the candidate layout; Raw exports carry the actual channel labels, positions and source-state subset. Average reference uses only those selected channels. Sensor readings, direct scalp field, source recording, inverse leadfield and frozen EEG feedback all use that same operator. Changing the subset invalidates the previous linked recording. Layout changes reset to the complete new layout and average reference. Fewer electrodes reduce spatial information; this does not establish inverse identifiability. Arbitrary unsolved electrode positions and FEM remain open.

## Inspecting the actual EEG feedback window

An explicit stop-and-analyze action reads a fresh controller snapshot from the Worker, pauses the model and stops further feedback. The retained single-sensor window (up to 1 s in the UI) enters the existing Raw/PSD/ERP/TFR workbench and JSON export as the actual measured 1000 Hz causal-filter output, without resynthesis or resampling. Export retains the frozen measurement operator, controller/filter state, upstream run and absolute window start; applied feedback events within the window are rebased to Raw time and remain unclassified pulses. The one-channel record has no fabricated infinity-reference data; re-reference, spatial topography and inverse interpretation are unavailable. Short windows cannot establish low-frequency rhythms or cognitive ERP mechanisms. This is distinct from offline centered-FIR network acquisition.

## Template BEM causal EEG feedback

The conductor choice is shared across the home and advanced views. BEM feedback uses the selected precomputed cortical node and its actual MNE BEM coefficient; it does not clamp template coordinates into a sphere or silently fall back when the BEM is unavailable. Snapshots/Raw export retain the conductor kind, HEAD coordinates, source revision, cortical vertex/hemisphere/atlas, direction, sensor geometry and reference. A frozen-source label identifies the controller's measurement model. Native filtering, model-clock decisions, exact replay and actual-window export use the existing controller pipeline.

The BEM geometry is internally MRI/HEAD registered; the native network E/I-to-dipole coupling remains an explicit uncalibrated assumption, with no TVB-to-human anatomical registration. Real-template matrix checks and a main-app Worker browser test cover source selection, BEM gain, feedback, replay and exact Raw/JSON samples. Numerical success does not validate physiology, FEM or human usability.
