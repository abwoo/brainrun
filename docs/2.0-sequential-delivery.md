# BrainRun 2.0 sequential delivery
Baseline: 043fc305 (manual physics MVP). The complete specification remains docs/brainrun-2.0-plan.md.

1. Configuration / recording / export consistency: restore active and pending configuration; mark next-run changes; reference transforms carry processing revision; invalidate stale epochs. This change implements this first work package.
2. Native continuous solver acquisition at 250/500 Hz, independent of display rate; anti-alias and event-clock validation.
3. Shared physical SourceState and analysis observation time; versioned dependent artifacts.
4. Manual physical interaction: scalp potential, fixed physical color scale, continuous orientation, electrode selection and waveforms.
5. Ready-to-use registered template BEM with permitted distribution.
6. Constrained electrode motion, multiple sources and conductivity-dependent forward models.
7. Physiology, multiscale and complete scientific/release acceptance, including actual-device and first-time-user evidence.

Each package must pass its necessary numerical checks, frontend build and a focused causal browser check in GitHub before automatic merge. No stage completion substitutes for later physiology or human usability acceptance.
