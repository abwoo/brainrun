# PR6 · 晚期成分机制（ERP 的 300–500 ms 成分从哪来）

> **状态：** PR-08/09（B2）已实现并通过方法学测试。分支 `pr6-eeg-analysis`。
> 模块：`app/src/lib/lateResponse.ts`；Python 独立对照：
> `scientific/eeg/late_response_reference.py`（SciPy DOP853）；
> 测试：`tests/pr6/waves-erp.test.mjs`（10/10）、`tests/pr6/test_waves_erp.py`（7/7）。
> 约束数据：OpenNeuro ds003061（CC0），sub-001 run-1，见
> `scientific/forward/public_eeg_reference_values.json` 与
> `docs/pr5-public-eeg-constraint.md`。

## 一句话结论

晚期成分的**形态**修好了、**幅度**没修好。慢突触电流机制让 oddball
在 300–500 ms 窗内从约 0 µV 变为 0.070 µV（峰 0.174 µV @352 ms，
oddball 选择性 8 倍），潜伏期落在 P300 窗内；但 y0 受 JR sigmoid
饱和限制在 ~0.16 mV，Pz 峰值天花板约 0.21 µV，与真实 P300（8.89 µV）
仍差约 51 倍。**幅度差距是结构性的，不是调参能解决的**，也没有靠
重缩放掩盖——见 §5 与守卫测试。

## 1. 问题：PR5 留下的结构性缺口

| 对照项（Pz，ds003061） | 实测 | PR5 的 JR 路线（p0=90，脉冲 120 1/s） | 结论 |
| --- | --- | --- | --- |
| P300 峰值 | 8.89 µV @410 ms | 0.17 µV @176 ms（早期峰；250–600 ms 窗内仅 −0.002 µV） | 幅度差 53.8 倍 |
| 300–500 ms 均值 | 6.94 µV | 0.0065 µV（oddball 脉冲 300 时 0.00006 µV） | 窗内基本无响应 |
| 刺激前基线 RMS | 6.07 µV | 模型基线 q = 0 | 无持续背景活动 |
| 主导频率 | alpha 峰 10.00 Hz（Pz） | 2.07 Hz（瞬时脉冲的谱峰，不是节律） | 无自发节律 |

前两项是本机制的主攻方向；后两项分别由 PR-08（alpha 极限环）与
PR-07 的噪声模型覆盖，本机制不管基线。

## 2. 机制：慢突触电流 + 延迟再入

快通路收到的传入驱动（40 ms 矩形刺激脉冲）同时驱动一个第二慢的
二阶突触核：

```
dr/dt = w
dw/dt = a_s² · (gain · stim(t − delay) − r) − 2·a_s·w,   a_s = 1/τ_slow
p(t)  = p0 + stim(t) + r(t)          （r 反馈回同一 JR 柱的传入端）
```

这是一个**带参数的动力学机制**，不是在输出上加一段固定 P300 波形：

- **慢突触电流**：同一传入驱动的两条突触电流——快 AMPA-like 经 JR
  自身的 y1 核（τ~10 ms），慢 NMDA-like 经本慢核（τ=200 ms）。慢核
  的输出形状由 ODE 演化出来，不由人指定。
- **延迟再入**：慢核驱动取延迟后的刺激 `stim(t − 100 ms)`，代表多突触
  再入环路（皮层-丘脑 / 皮层-皮层）的传导时间。延迟与 τ_slow 共同决定
  晚期峰落在 300–400 ms，而不是刺激后立刻出现。
- **oddball 选择性**：标准与靶刺激走同一慢核，区别只在驱动幅度
  （120 vs 300 1/s）。慢核是线性滤波器，但柱子的 sigmoid 是非线性的：
  小驱动只把柱子推到阈值附近、大驱动把它短暂推近上分支，于是晚期窗
  均值 oddball 0.070 µV vs standard 0.009 µV（8 倍），差异波峰
  0.166 µV @352 ms。
- **静息时 r = 0 精确成立**（stim=0 ⇒ 目标 0 ⇒ r 恒 0），基线就是普通
  JR p0=90 低分支不动点；机制不改变静息态、不引入漂移。

### 参数（TS 默认 = Python 对照同值）

| 参数 | 默认值 | 单位 | 说明 |
| --- | --- | --- | --- |
| `tauSlowMs` τ_slow | 200 | ms | 慢核时间常数（NMDA-like 慢电流的量级；设计稿要求 150–300 ms） |
| `delayMs` | 100 | ms | 再入延迟（多突触环路传导时间） |
| `slowGain` | 2.5 | 无量纲 | 慢核增益（驱动 = gain × 延迟后刺激） |
| `slowMaxPerS` | 5000 | 1/s | 慢核输出 r 的数值守卫上限（正常使用下永不触发：r ≤ gain×1000） |
| 刺激时长 | 40 | ms | 矩形脉冲（沿用 PR5 协议） |
| 标准驱动 | 120 | 1/s | 沿用 PR5 脉冲幅度 |
| 靶刺激驱动 | 300 | 1/s | 2.5 倍于标准（任务差异，不是拟合值） |
| Pz 增益 | 0.16 | µV/(nA·m) | PR5 球形头中央值（范围 0.130–0.188，只作不确定性说明） |

### 安全边界（实测，不是假设）

- 增益 ≤3.0：刺激后回到基线（2000 ms 后 |q| ≈ 0.0002 nA·m）。
- 增益 4.0：锁存——慢反馈把柱子推上 JR 上分支，2000 ms 后 q 仍
  0.85 nA·m（峰值的 ~75%）。增益 6 同样锁存。
- 默认 2.5 距锁存边界约 60% 裕量。`detectLatch`（末尾 100 ms 内 |q|
  均值 > 峰值 |q| 的 5% 即判锁存）两边都测过：默认不锁存、增益 6 锁存
  且被检出。`validateLateResponseParams` 拒绝非法参数；`step` 内有
  JR 同款发散守卫（y0/y1/y2 越出 [−10, 100] mV、非有限值、r 超守卫即抛错）。

## 3. PR-08：JR p0=220 alpha 极限环实测

JR p0=220 的标准工作点是约 10.5 Hz 极限环（不是不动点——
`equilibrateJansenRit` 在此会大声失败，故从零起跑、不做不动点平衡）。
12 s 连续记录、去掉前 2 s，剩 10 s（250 Hz），Welch PSD（nFft=1024，
df≈0.244 Hz，周期 Hann、50% 重叠，先减均值，与 scipy 同口径）：

| 量 | y0 | Pz EEG（q×0.16） | ds003061 实测 |
| --- | --- | --- | --- |
| alpha 峰（8–13 Hz 内） | **10.99 Hz** | **10.99 Hz** | Pz 10.00 Hz / Oz 9.25 Hz |
| 与 Pz 偏差 | +0.99 Hz（+9.9%） | 同左 | — |
| 与 Oz 偏差 | +1.74 Hz（+18.8%） | 同左 | — |
| alpha 功率占比（占 1–40 Hz） | 99.8% | 99.8% | Pz 30.3% / Oz 69.3% |
| RMS | 0.0131 mV | 0.0167 µV | Pz 基线 RMS 6.07 µV |

解读：

- **频率对上量级**：10.99 Hz 落在 alpha 频段内，距真实 Pz 峰不到 1 Hz。
  这是柱模型自身的自发节律（极限环），不是叠加的正弦——PR5 的 2.07 Hz
  只是瞬时脉冲的谱峰，两者性质不同。
- **占比虚高是已知局限**：纯极限环没有宽带背景，alpha 占 99.8%；
  真实 Pz 只有 30.3%（低频功率占主导）、Oz 69.3%。模型缺背景噪声，
  占比数字不能直接比——报告里如实写，不修。
- **幅度仍差 ~360 倍**：Pz RMS 0.017 µV vs 真实 6.07 µV（单源、无背景）。
  频率机制与幅度机制是两回事：前者修好了，后者没修好。

预设规则（已写进 WavesTab 界面）：Alpha 探索 = JR p0=220；其余频段
只作同一份信号的频段功率读数，不为每个频段各编一个“节律”；
Oscillatory 10 Hz 正弦驱动仍标注为外部驱动，不是自发节律。

## 4. PR-09：oddball 实验与 ERP 管线

- **事件系统**：事件时间戳是仿真时钟（累计 ISI=1000 ms），不是浏览器
  墙钟；事件类型/条件（standard/oddball）、驱动（120/300 1/s，单位 jr）、
  试次编号；参数快照（JR 参数、慢机制参数、形态学、Pz 增益、协议）随
  `runOddballExperiment` 的结果对象一起返回（`EegEvent` 类型无快照字段，
  是 B1 拥有的类型，不改它）。
- **实验**：默认 40 试次（32 标准 + 8 oddball，每 5 个 1 个靶刺激，
  比例 4:1 ≈ 真实 476:99）；每试次独立从平衡基线起跑（−200–800 ms）。
  相邻 epoch 在 800/−200 ms 边界点共享一个采样点（ISI=1000 时），两端
  都在静息态、数值一致到 ~1e-4 µV，填充时后一试次覆盖该共享点。
- **分段**：MNE 口径（A1 的 `epochRecording`）：−200–800 ms、基线
  −200–0 ms、峰峰值 >150 µV 剔除；平均/SEM（`averageEpochs`）；峰值
  （250–600 ms 窗，MNE `get_peak(mode='abs')` 口径）与窗均值（300–500 ms）；
  差异波（oddball − standard，SEM 按独立试次传播）。
- **试次变异性**：确定性模型本身无试次变异（无噪声时 SEM 为 0，只有
  边界共享点带来 ~1e-4 µV 级数值差异）。试次数量效应演示用**测量噪声**
  （白噪声、有种子、可复现，明确标注为测量噪声、不是神经源活动；
  默认 0；B1 的 PR-07 全噪声模型落地后由壳层替换）。0.25 µV 噪声下，
  oddball n=2 → n=8 时窗内 SEM 约减半（1/√n）。
- **峰值挑选偏差**（实测发现，已写进测试注释）：峰值是窗内 |值| 的
  最大值，取最大本身会把噪声正偏抬进峰值（n=8、噪声 0.25 µV 时噪声峰
  可达 0.43 µV，而无噪声峰 0.174 µV）。收敛断言只对无偏的窗均值做，
  不对噪声下的峰值做。

## 5. 残留缺口（诚实清单）

1. **幅度仍是结构性缺口**：oddball 峰 0.174 µV vs 真实 8.89 µV（差 51 倍），
   300–500 ms 均值 0.070 vs 6.94 µV（差 99 倍）。原因不在慢核增益——
   y0 受 JR sigmoid 饱和限制在 ~0.16 mV，q 峰 ≲1.3 nA·m，Pz 天花板约
   0.21 µV；再调增益只会把柱子推上锁存分支，不会把峰值推上去。
   要修幅度，需要 PR6/PR7 的真实节律机制与 ERP 生成机制（更多源、
   更大同步群体、或接受“教学仿真”定位），不是本机制的任务。
2. **乘积不可辨识，守卫留着**：N×coherence×pA×mm 乘积翻倍即输出翻倍
   （测试覆盖），Pz 增益固定用 PR5 中央值 0.16，不按实测/模型比值反推。
   任何“放大 51 倍对上 P300”的写法都是把乘积调到对上，不等于证实了
   细胞数或同步性——测试里有专门的守卫断言防止这种写法。
3. **基线仍是 0**：模型无持续背景活动，刺激前 RMS 0 vs 真实 6.07 µV。
   基线要靠 PR-07 的噪声/背景模型或 PR-07–PR-08 的持续节律叠加，不是
   本机制的任务。
4. **alpha 占比虚高**：纯极限环 alpha 占 99.8%，真实 Pz 30.3%——模型无
   宽带背景（见 §3）。
5. **锁存边界近**：默认增益 2.5 距锁存边界（~3.5–4）约 60% 裕量；增益
   是自由参数，误调到 4 以上会锁存（但会被 `detectLatch` 检出，不静默通过）。
6. **试次独立重启**：各试次独立从基线起跑，无跨试次适应/学习；ISI 只定
   事件时间戳，不影响动力学。真实 oddball 有习惯化等跨试次效应，本批不做。

## 6. 数值对照方法（可复现）

- TS RK4（dt=0.5 ms）vs Python DOP853（rtol=1e-12）：oddball 试次逐点差
  y0 最大 9.7e-8 mV、q 最大 7.8e-7 nA·m（<1e-6 级）。做到这一点需要两处
  正确处理（都已写进代码注释，调试过程有据可查）：
  - RK4 各级取该级时刻的驱动与级状态的 r（不是全步共用步首值）——否则
    是一阶误差，实测 dt=0.5 ms 时 y0 差 4.5e-4 mV；
  - k4 级在步末取左极限（t+dt−ε）——否则相当于把脉冲缩短 dt/6，实测
    在 t=40 ms 处引入 3e-4 mV 的一阶误差。
  - Python 侧在驱动边沿（0、40 ms）与延迟边沿（100、140 ms）处分段积分，
    DOP853 永不跨过间断点（rtol=1e-9 时跨间断点会错 0.13 mV，实测）。
- MNE 对照：同一份 10 试次记录经 MNE `Epochs`/`Evoked`（基线、剔除、
  平均、峰值、窗均值）与 numpy 独立计算逐项一致（峰值允差 0.01 µV、
  潜伏期 4 ms）。
- Alpha：TS Welch 与 Python scipy Welch 同口径（nFft=1024、周期 Hann、
  50% 重叠、先减均值），峰位一致到一格 bin（0.244 Hz）以内。
