## Remaining implementation order

1. Resolve reproducible operation/solver/data-flow failures before extending models. Repeated-input recovery is the current delivery.
2. Extend geometric validation and anatomical FEM with matching geometry/conductivity/source support. A spherical numerical solver is not a substitute for this.
3. Add compatible licensed human connectivity/atlas data and verified transforms; do not visually scale unrelated coordinates into apparent registration.
4. Connect multiscale source generation with explicit identifiable parameters and reference constraints before claiming calibrated biology.
5. Add mechanism-specific rhythm and cognitive ERP models with independent reference comparisons. Existing band/ERP analysis is not generation-mechanism validation.
6. Carry out physical-device and first-time-user acceptance. Cloud tests cannot supply these human observations.

No human/device test or new physiological calibration has been performed for this delivery. No result should be advertised as the complete validated 2.0 platform while the above rows remain open.
