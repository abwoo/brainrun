# PR-14 · 脑刺激实验室（TES / TMS / 感觉输入）

计划 PR-14（brainrun 2.0 plan §15.3 感觉输入实验室、§15.4 脑刺激实验室）。
实现：`app/src/lib/stimulation.ts`（纯 TS，不 import 任何 npm 包）；

单位一律：mm / nA·m / µV / ms / Hz / mA / V/m。
坐标：球心头 RAS（mm），与 `sphereForward.ts` 同框（球半径 95 mm，

## 0. 分级总表

| 级别 | 输入 → 输出 | 物理完整性 | 明确不声称的事 |
|---|---|---|---|
| A | 写清的驱动 → WC/JR 柱 q(t) | 直接模型输入 | 不是完整 tES/TMS 物理刺激 |
| B | 电极（位置、mA）→ 头内电场 V/m | 均匀导体点源解析解 | 不是 SimNIBS/FEM、无颅骨/边界 |
| C | 线圈（半径、匝数、dI/dt）→ 感应电场 V/m | 均匀导体圆环解析积分 | 不是真实头模型、无组织边界 |
| D | 目标处法向电场分量 → 未校准增益 → 柱响应 q(t) → Pz 代理 EEG | 有定义的映射链 | 电场强 ≠ 真实大脑必然兴奋/抑制；增益未经校准 |

## 1. Level A — 直接神经模型输入

`runDirectDrive({model, drive, durationMs, stimOnMs, totalMs, sampleDtMs})`：
矩形附加输入，默认窗口 [100, 100+duration) ms（PR5 对照协议），
默认总窗 600 ms、采样 4 ms。

- WC：drive 为模型单位，允许 |drive| ≤ 10（柱 `step()` 的既有限制）。
- JR：drive 为 1/s，允许 [0, 1000]。
- 输出 `q(t)`（假设偶极耦合，PR5）与 Pz 代理 EEG `q × 0.16 µV/(nA·m)`
  （与 PR6 `PZ_GAIN_UV_PER_NAM` 同值）。

验证：WC drive 1.4、40 ms 的峰值 |q| > 0.5 nA·m；drive 0 时峰值 < 1e-12。

## 2. Level B — TES 电场

### 2.1 公式

无限均匀各向同性导体中的点电流源（单极子）叠加：

```
E(r) = Σ_k I_k (r − r_k) / (4πσ |r − r_k|³)
```

`I_k` 为第 k 个电极的注入电流（A），`r_k` 为电极位置（m），
σ 默认 0.33 S/m。电场对电流严格线性：电流翻倍则场翻倍
（实测相对误差 < 1e-12）。

### 2.2 约束（`validateTesElectrodes` / 目标校验）

- 电极 2–8 个，位置必须落在 95 mm 头皮球面上（允差 ±1 mm）；
- 每个电极 |I| ≤ 4 mA（典型 tDCS 为 0–2 mA）；
- 电流总和为零（电荷守恒，允差 1e-9 mA），阳极 +、阴极 −；
- 目标必须在脑球内（r ≤ 85.5 mm），且距每个电极 ≥ 5 mm
  （点源奇点保护）。

### 2.3 近似与局限（必须如实写清）

- 无颅骨：真实颅骨电导率约 0.004 S/m，会分走大部分电压；
  本模型用均匀 σ=0.33 S/m，**会高估皮层电场**，尤其电极附近。
- 无组织边界、无各向异性、无真实头形；电极是点源，不是真实
  海绵/凝胶电极的面分布。
- 电场方向：阳极正下方目标处电场主要向下（−z），与直觉一致。

### 2.4 验证数值（默认配置：阳极 [0,0,95] +2 mA，阴极 [0,−95,0] −2 mA）

| 目标（mm） | \|E\|（V/m） | 说明 |
|---|---|---|
| [0, 0, 70]（阳极下皮层） | **0.793** | Ez = −0.792，Ex = 0（对称性） |
| [0, 0, 16]（脑中心） | 0.100 | 深部场小一个量级 |
| 网格最大（40 mm 网格，脑内） | 2.164 | 在最靠近电极的采样点 |

- TS vs Python 闭式解逐点最大差 **3.47e-18 V/m**（容差 1e-9）。
- σ 减半则场翻倍（实测相对误差 < 1e-12）。

## 3. Level C — TMS 电磁场

### 3.1 公式

均匀导体中圆形线圈的法拉第感应电场（准静态，矢势环路积分）：

```
E(r) = −μ₀ N (dI/dt) / (4π) · ∮ dl / |r − r′|
```

μ₀ = 4π×10⁻⁷ H/m；N 为匝数；dI/dt 为电流变化率（A/s）。
环路积分无量纲（dl 与 |r−r′| 均为 mm，比值相消），
E 的单位由 μ₀·(A/s) 给出（V/m）。
积分用闭合环路上的梯形法则，默认 360 段；被积函数是周期函数，
梯形法则收敛极快。

组织模型：均匀 σ = 0.33 S/m。电导率**不进入 E 的计算**
（它进入电流密度 J = σE）；σ 在结果中记录为所假设的均匀组织模型。

### 3.2 约束

- 线圈半径 10–100 mm，匝数 1–50（整数），|dI/dt| ≤ 2×10⁸ A/s；
- 线圈中心 [0, 0, 102] mm、轴向 +Z（贴头皮顶部），目标在脑球内；
- 目标距线圈导线 ≥ 2 mm（细导线奇点保护）。

### 3.3 公式的直接推论（测试覆盖，不是 bug）

- **轴上电场为零**：目标在轴上时环路贡献对称抵消（实测 < 1e-9 V/m）。
- **电场是方位角方向**：垂直于线圈轴、垂直于径向偏移；
  目标在 +x 偏移、dI/dt > 0 时场沿 −y。
- **E 随 N 与 dI/dt 线性变化**（实测 dI/dt 翻倍则场翻倍，误差 < 1e-9）。

### 3.4 近似与局限

- 细导线圆环，无 8 字形线圈、无铁芯、无线圈外壳；
- 无颅骨/脑组织边界、无感应电流的二次场（均匀导体中无面电荷，
  故无标势项；真实头有边界，会有抵消/增强）；
- 单脉冲 dI/dt 为常数输入，不模拟真实刺激器的双相电流波形。

### 3.5 验证数值（默认线圈：半径 35 mm、10 匝、dI/dt = 1×10⁸ A/s）

| 目标（mm） | \|E\|（V/m） |
|---|---|
| [30, 0, 70]（轴偏 30 mm 的皮层） | **84.99**（沿 −y） |
| [0, 0, 70]（轴上） | 0 |
| [45, 0, 70] | 87.5（dI/dt = 5×10⁷ A/s 时为 43.7） |

- TS（360 段）vs Python（3600 段）逐点最大差 **1.42e-14 V/m**（容差 1e-4）。
- 360 段 vs 3600 段差 < 1e-6 V/m（fixture 内双值记录）。

### 3.6 与 TES 的量级对比（结果，不是 bug）

默认目标处 TMS 场 85 V/m、TES 场 0.79 V/m，相差约 **107 倍**。
这正是两类刺激的真实量级关系：tDCS 是亚阈值调制（~0.1–1 V/m），
TMS 是超阈值感应（~100 V/m）。

## 4. Level D — 电场到神经响应

### 4.1 映射链

```
场矢量 E（V/m，Level B 或 C）
  → 沿皮层法向的分量 E_n = E·n̂（V/m，n̂ 为单位法向）
  → 未校准增益：WC drive = g_WC · E_n；JR drive = g_JR · E_n
  → WC/JR 柱响应 q(t) → Pz 代理 EEG（×0.16 µV/(nA·m)）
```

默认增益（用户可见、可改）：

| 柱 | 默认增益 | 100 V/m 对应驱动 | 选取依据 |
|---|---|---|---|
| WC | 0.01 模型单位/(V/m) | 1.0 模型单位 | 等于 PR5 WC 对照脉冲量级（1.4） |
| JR | 1.0 (1/s)/(V/m) | 100 1/s | 等于 PR5 JR 对照脉冲量级（120 1/s） |

### 4.2 诚实性规则（写进代码，不止写进文档）

- 增益**未经人体数据校准**；超出柱输入范围时抛错，
  **不静默钳制**（`fieldToDrive` 在 WC |drive|>10 或 JR drive 超出
  [0, 1000] 1/s 时抛 `RangeError`）。
- TES 量级场（~0.79 V/m）在默认增益下几乎不动柱子
  （WC drive 0.0079、JR drive 0.79 1/s）；TMS 量级场才动。
  这个量级落差是结果，不是需要修掉的 bug。
- **电场强不等于真实大脑必然兴奋或抑制**：响应模型本身就是假设；
  同一电场在不同皮层法向、不同柱模型下驱动不同，甚至符号不同
  （法向分量为负时 JR 驱动为负值区间外，抛错而不是反号）。

### 4.3 验证数值（法向 +Z，驱动窗 100–200 ms，总窗 600 ms）

WC 峰值 |q|（nA·m）：

| E_n（V/m） | 0 | 25 | 50 | 100 | 200 |
|---|---|---|---|---|---|
| 峰值 \|q\| | 0 | 0.512 | 1.918 | 4.057 | 4.550 |

JR 峰值 |q|（nA·m）：

| E_n（V/m） | 0 | 25 | 50 | 100 | 200 |
|---|---|---|---|---|---|
| 峰值 \|q\| | 0 | 0.065 | 1.024 | 1.125 | 1.171 |

- 两条路线峰值都随场单调不减（WC、JR 各 5 点，测试覆盖），
  峰值处 q 的符号均为正（无故不反号）。
- **JR 在 25→50 V/m 之间跳变（0.065→1.024）是 Jansen–Rit
  p0=90 低分支的双稳态翻转，不是校准过的剂量–反应关系。**
  同一现象在 PR6 晚期机制里已有记录（增益 ≥4.0 锁存）。
  JR 的 Level D 只宜在小场（≲25 V/m，默认增益下）作定性演示。
- TS RK4 vs Python DOP853 q(t) 逐点最大差：WC **2.01e-6 nA·m**
  （容差 1e-5）、JR **1.81e-9 nA·m**（容差 1e-6）。

## 5. 感觉输入实验室

### 5.1 视觉闪烁

映射（写清的定义，不是生理复现）：

```
drive(t) = 强度 × 0.5 × sin(2π f t)，模型单位，零均值
```

- 柱：WC。JR 不能用：JR 的 `step()` 拒绝负输入，且 p0=90 低分支
  在持续正驱动下会锁存，无法跟踪周期输入（实测：JR 闪烁 FFT 峰
  落在 ~1 Hz 而非刺激频率，见 debug-rounds-b.md）。
- 驱动在 RK4 步**中点**采样（见 §6.2），不是步起点。
- 响应测量复用 PR6 `welchPsd`（不重新实现 PSD）。

验证（4000 ms，250 Hz 采样，Welch nFft=256，df≈0.977 Hz）：

| 刺激频率（Hz） | Welch 峰（Hz） | 峰值 \|q\|（nA·m，强度 1） |
|---|---|---|
| 8 | 7.81 | 1.766 |
| 10 | 9.77 | 1.566 |
| 20 | 19.53 | 0.985 |

- 强度扫描（10 Hz）：峰值 |q| 随强度单调增大（0.25→约 0.44，1→1.566）。
- TS vs Python 连续驱动 DOP853 q(t) 最大差 **3.41e-4 nA·m**（容差 1e-3）。

### 5.2 简化听觉刺激

映射：矩形 tone burst 串。

```
drive(t) = 强度 × 1.0 模型单位（burst 内），否则 0
```

- burst 默认 50 ms，5 个，首个在 500 ms，ISI 可选 250/500/1000 ms。
- **音调频率（Hz）是元数据**：校验范围 [20, 20000] Hz、记录在结果里，
  但**不进入动力学**——1 ms 柱步长无法分辨 kHz 载波，也不声称任何
  音调定位映射。仅音调不同、包络相同的两次运行给出逐值相同的柱轨迹
  （测试覆盖：440 Hz 与 4000 Hz 的 q(t) `deepEqual`）。
- ISI 扫描指标：固定窗 [500, 1500] ms 内平均 |q|（不是全程均值；
  全程均值在 ISI 250 与 500 时相同，因为 5 个 burst 的总驱动能量相同
  ——见 debug-rounds-b.md）。

验证：

| ISI（ms） | 固定窗平均 \|q\|（nA·m） |
|---|---|
| 250 | 0.862 |
| 500 | 0.430 |
| 1000 | 0.215 |

- 强度扫描（ISI 500）：峰值 |q| 0.512 / 1.918 / 4.057（强度 0.25 / 0.5 / 1）。
- TS vs Python q(t) 最大差 **2.64e-6 nA·m**（容差 1e-5）。

### 5.3 重复刺激

听觉 burst 串本身就是重复刺激实验：WC 柱无适应机制，
各 burst 的峰值响应相同（这是模型的局限，如实记录）；
ISI 效应体现在固定窗内的 burst 个数上，不体现在单 burst 峰值上。

## 6. 数值方法说明

### 6.1 驱动采样：步中点

`runColumnResponse` 在每一步用步中点时刻 `t + dt/2` 的驱动值
作为该步的常数输入（矩形驱动的边沿在整数 ms 上，中点采样不改变
矩形驱动的结果；正弦驱动的采样误差由一阶降为二阶）。
实测：闪烁 q(t) 与连续 DOP853 的差从 0.047 降到 **3.41e-4 nA·m**。

### 6.2 Python 参考的两个已修 bug（详见 debug-rounds-b.md）

1. `solve_ivp` 带 `t_eval` 时 `sol.y[:, -1]` 是最后一个**采样点**的
   状态，不是分段终点；burst 结束在非采样网格点（550 ms）时，
   下一段会从 2 ms 前的旧状态起跑（q 差达 0.19 nA·m）。
   已修：分段终点显式补积分。
2. `t_eval` 为空的分段会把求解器内部自适应步点当采样点追加进序列，
   峰值取到网格外的值。已修：空 `t_eval` 的分段只推进状态。

### 6.3 容差表（由实测误差底定）

| 对照 | 容差 | 实测最大差 |
|---|---|---|
| TES 场 vs 闭式解 | 1e-9 V/m | 3.47e-18 V/m |
| TMS 场 vs 3600 段环路积分 | 1e-4 V/m | 1.42e-14 V/m |
| TMS 360 vs 3600 段 | 1e-6 V/m | < 1e-6 V/m |
| Level D WC q(t) vs DOP853 | 1e-5 nA·m | 2.01e-6 nA·m |
| Level D JR q(t) vs DOP853 | 1e-6 nA·m | 1.81e-9 nA·m |
| 闪烁 WC q(t) vs 连续 DOP853 | 1e-3 nA·m | 3.41e-4 nA·m |
| 听觉 WC q(t) vs DOP853 | 1e-5 nA·m | 2.64e-6 nA·m |
