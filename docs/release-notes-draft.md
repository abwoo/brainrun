## 定位

**教学仿真（educational simulation）。** BrainRun 2.0 是一个可以在浏览器里
直接动手玩的 3D 大脑神经动力学与 EEG 仿真教学平台：点脑区、调参数、
拖电流源、跑 ERP 实验，全部是真实模型在算，没有假动画。
但全部 EEG/ERP 输出都是**未校准的模型演示，不是真实人脑的预测**。
未校准的模型结果不得在任何一处被表述为真实人脑参数或真实人脑预测。
详见 `docs/model-spec.md` §1 与 §13。

## 本版包含的内容

### 全脑 Wilson–Cowan 网络（Phase 1–4）

- 76 区演示连接组（TVB 示例数据），Heun 积分、1 ms 步长、传导延迟
  （速度 3.0 mm/ms），Rust/WASM 引擎与 Python 参考实现逐数对照。
- 演示预设：TVB A-set 只改 θ_e（0 → 1.0），G = 0.35；背景活动三档
  （安静 / 自发 OU σ = 0.10 / 振荡 10 Hz 正弦外部驱动）；实验快照
  （手动 + 按住自动快照，恢复后轨迹逐值一致）；连接权重可编辑；
  四个滑杆（刺激强度 0.5–2.0、持续时间 20–500 ms、c_ei 3–8、G 0–0.4）。

### PR5 物理核心

- 均匀无限导体解析偶极子（12 个示意传感器，教学基线）；
- MNE 四层球形头正向模型（半径 95 mm，电导率 0.33 / 1.0 / 0.004 /
  0.33 S/m；导联 10-20 = 19、10-10 = 94、10-05 = 343，径向投影到球面）；
- fsaverage 真实 MRI/BEM（本地导入，用户自备数据；不公开分发）；
- 局部 Wilson–Cowan 皮层柱与 Jansen–Rit 独立验证路线（同一套显式假设链，
  N = 1,000,000、同步比例 0.08、200/100 pA、0.5 mm；JR 峰值比 WC 的 0.234，
  JR 峰值晚 68 ms）；
- 公开 EEG 约束（OpenNeuro ds003061，CC0，sub-001 run-1）。

### PR6 EEG 分析

- 多导 EEG（250 Hz，参考平均 / 无限远 / 电极，噪声白 / 粉红 / 50 Hz /
  慢漂移四成分）；频谱与频段（JR p0 = 220 极限环 alpha 峰 10.99 Hz）；
  ERP 与晚期成分机制（慢突触电流 + 延迟再入，oddball 峰 0.174 µV
  @352 ms）；时频（STFT / Morlet / multitaper，ERSP 与 ITC）；地形
  （2D 球面样条插值与 3D 345 点正向计算值严格区分）；源定位
  （偶极子拟合 + MNE 逆解，盲测）。

### PR7 多尺度与高级实验

- 细胞级：LIF、Hodgkin–Huxley、多房室神经元与跨尺度耦合
  （NEURON 9.0.2 交叉验证）；
- 脑刺激实验室：TES / TMS / 感觉输入，分 A–D 四级
  （TES 默认目标处 0.79 V/m，TMS 85 V/m）；
- 对照实验：双脑 A/B、时间机器、闭环控制、跨试次适应；
  深度加权 / dSPM / eLORETA（部分改善，未根治）。

## 许可状态摘要

- **代码：** MIT（根目录 `LICENSE`；第三方说明见 `NOTICE.md`）。
- **TVB 示例数据（演示连接组）：再分发许可仍不确定。**
  `tvb-data` 仓库 LICENSE 全文针对 TVB 软件（GPLv3），未单独说明数据文件
  是否同样适用；GitHub API 判定为 Other / NOASSERTION；Zenodo 记录
  10128131 的元数据里没有 license 字段。原始数据与预处理衍生资产均不进
  仓库，构建时下载并生成（`scripts/prepare-brain-data/fetch.py`，
  提交钉死 `f1a3e7d`，SHA-256 校验）。公开站点仍会向访问者提供这些衍生
  字节；彻底消除不确定性需要 TVB 方面的书面确认或换用许可明确的替代数据。
  发邮件与重写公开历史**仍未定**（等用户拍板）。详见 `docs/data-license.md`。
- **fsaverage 派生数据：仍不得公开再分发。** FreeSurfer Part B 本身不禁止
  再分发，但 §3 第三方权利（40 名受试者底层 MRI 数据、`aparc` 图谱权利）
  未清除，且实际副本来自 MNE 的 OSF 镜像、来源链未核实；随附许可包尚未制作。
  只走本地导入（`.local-assets/`）。详见 `docs/pr5-license-and-zero-config.md`。
- **onavg 皮层表面模板：CC0，可自由再分发。** 但只有皮层表面，没有头皮/
  颅骨壳、电极位置与已验证配准，零配置真实 BEM 尚未建成（需单独立项验证）。
- **公开 EEG 约束数据：** OpenNeuro ds003061，CC0。
