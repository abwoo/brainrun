# Brain Physics Playground — 设计规范（Design Spec）

版本：v1.0（Phase 1）
依据：`phase0-verification.md` 第 2 节（CHIMERA 源码实测），以及 Plan v1.0 第 2 节。
本规范是指导实现的唯一视觉依据；与 CHIMERA 原文不一致处以本文件为准，并注明来源。

## 1. 风格定位

CHIMERA 式的深色科学仪器风（WarGames NORAD 屏幕风）：近乎纯黑的底、
细发光线条、无填充面板。视觉重点永远是可操作的三维大脑本身，
而不是仪表盘或装饰。

禁止：卡片阴影、玻璃拟物效果、厚重圆角、渐变面板、SaaS Dashboard 式
大面积色块。

## 2. 颜色

色值全部来自 CHIMERA 源码 `src/ui/colors.ts` 实测（见 phase0-verification.md §2），
除背景色外不得擅自改动。

| 用途 | 色值 | 来源 |
|---|---|---|
| 主背景 | `#05080C` | Plan v1.0 指定值。注意：CHIMERA 本身背景是纯黑 `#000000`；本项目用 `#05080C` 是 Plan 的选择，比纯黑略带蓝，便于区分面板与背景。两者关系：`#05080C` 是本项目背景，`#000000` 是 CHIMERA 原值，不可混称。 |
| 结构蓝（主） | `#4fb6f2` | CHIMERA `blue`，身体与结构 |
| 结构蓝（中） | `#3487c4` | CHIMERA `blueMid` |
| 结构蓝（暗） | `#1f5f8c` | CHIMERA `blueDim` |
| 细线框 | `#133954` | CHIMERA `frame` |
| 信号琥珀 | `#ffb340` | CHIMERA `amber`，声音/动态信号 |
| 暗琥珀（热色阶低端） | `#3a2408` | CHIMERA heat 色阶起点 |
| 亮琥珀（热色阶高端） | `#fff8ec` | CHIMERA heat 色阶终点 |
| 文字白 | `#eef6f8` | CHIMERA 白 |
| 抑制/负向变化 | 冷青绿（具体色值待 Phase 3 随模型定义，Phase 1 不使用） | Plan v1.0 |
| 绿色 / 红色 / 粉色 | `#5be381` / `#ff5d40` / `#ff73cf` | CHIMERA 四个控制槽位颜色，Phase 1 仅作参考，不滥用 |

规则：
- 蓝色 = 解剖结构、分区、连接；琥珀色 = 由模型算出的动态信号。
  Phase 1 没有仿真，因此界面上不得出现任何琥珀色“活动”表现。
- 发光：低强度局部 Glow。CHIMERA 的做法是 Canvas 2D 用
  `globalCompositeOperation = 'lighter'` 画锐利线条，再把画布缩放到
  低分辨率层模糊后叠回做辉光；WebGL 只在 trace 证明需要时才用。
  本项目 3D 视图用 Three.js（见 §5 说明），辉光克制，不得满屏泛光。

## 3. 字体

- CHIMERA 用 Hershey Simplex 单线大写字母（`public/fonts/`）。
- 本项目 Phase 1 **不引入外部字体下载**：标题用系统无衬线字体
  （`system-ui, "Helvetica Neue", Arial, sans-serif`），全部大写、
  字距略放宽，模拟 Hershey 风格的仪器感；数字用等宽字体
  （`ui-monospace, "SF Mono", Menlo, Consolas, monospace`）。
- 标题字号 11–13px，字重 600；正文 12–13px；读数等宽 12–14px。
- 不得使用衬线体、圆体、手写体。

## 4. 布局（桌面端）

```
┌──────────────────────────────────────────────────┐
│ BRAIN PHYSICS       PLAY   CONNECT   RESET   ▶   │
├───────────────────────────┬──────────────────────┤
│                           │  LIVE ACTIVITY       │
│                           │  (Phase 1: 离线提示)  │
│      3D LIVE BRAIN        ├──────────────────────┤
│                           │  PARAMETERS          │
│    可旋转、可点击、        │  (Phase 1: 置灰禁用)  │
│    可刺激的真实脑结构      │                      │
│                           ├──────────────────────┤
│                           │  REGION / CONNECTION │
│                           │  当前脑区与响应信息   │
├───────────────────────────┴──────────────────────┤
│  点击刺激 · 拖动旋转 · 滚轮缩放        TIME --.-- s │
└──────────────────────────────────────────────────┘
```

- 左侧 3D 区占 65%–70%，右侧仪表列占 30%–35%。
- 右侧自上而下三块仪表：LIVE ACTIVITY、PARAMETERS、REGION / CONNECTION。
- 窄于约 1100px 时纵向堆叠（与 CHIMERA 一致）。
- 每个仪表是一个 `Screen`：1px 细线框（`#133954`）、左上角大写标题、
  无填充背景、无阴影。面板之间留 8px 间隙。
- 顶栏：左侧 `BRAIN PHYSICS` 大写标题；右侧 PLAY / CONNECT / RESET
  为带框大写标签（Chips 风格，点亮表示开启），不是实心按钮。
- 底栏：左侧操作提示，右侧仿真时间读数。

## 5. 三维大脑本体

- 必须用真实皮层网格（TVB `cortex_16384`：16384 顶点、32760 三角面），
  不是球体拼成的大脑。左右半球真实折叠可见，脑沟脑回有空间层次。
- 材质：暗蓝灰底色 + 冰蓝色边缘线感，光照表现曲率；不得让大脑表面
  像果冻一样膨胀收缩——活动只用颜色/亮度/叠加层表示（Phase 1 无活动，
  故表面保持静态解剖外观）。
- 与 CHIMERA 的区别（必须如实说明）：CHIMERA 的 3D 视图是正中矢状
  切面的头、以发光线条画出的线框风格，不是写实 shaded 实体网格。
  本项目借鉴其视觉语言与仪表构图，但 3D 本体按 Plan 要求做实体皮层
  网格渲染，不可对外声称“CHIMERA 本身就是这么做的”。
- 脑区高亮：悬停时目标脑区边界轻微蓝色高亮（`#4fb6f2`，低强度）；
  选中时同一脑区保持高亮并在 REGION 面板显示信息。
- 连接线：只画选中脑区的前 5 条主要连接弧线；明确标注为“结构连接
  示意”，不是白质纤维追踪结果。
- 相机：OrbitControls 旋转/缩放/平移；双击背景平滑恢复默认视角。

## 6. 控件

- 参数用 CHIMERA 式编码器旋钮（Encoder）：底层原生 range input，
  上层画旋钮与大数字；每屏 4 个旋钮。
- Phase 1 的四个旋钮（刺激强度、持续时间、兴奋/抑制、连接强度）
  全部置灰禁用，并注明 “PHASE 3 接入”，不得假装可调。
- PLAY：控制相机自动缓慢旋转的开关。这是相机运动，不是神经活动，
  按钮文字必须如实反映（PLAY = 恢复旋转 / 暂停旋转）。
- RESET：恢复默认视角并清除选中。

## 7. 诚实性规则（硬规则，与视觉同等重要）

- Phase 1 界面必须明确标注 `PHASE 1 PROTOTYPE — NO SIMULATION YET`。
- LIVE ACTIVITY 不画任何波形，只显示 `SIMULATION OFFLINE — Phase 3 接入`。
- 时间读数显示 `--.-- s`，不得伪造仿真时间。
- 禁止任何随机活动、假波形、假闪烁冒充仿真结果。
- 禁止为好看修改顶点位置：网格顶点一律按 TVB 原始坐标渲染，
  只做整体居中/缩放以适配相机，不得逐顶点变形。

## 8. Phase 4 附录（v1.1）：视觉与交互打磨

本节记录 Phase 4 相对 v1.0 的具体改动；未提及处仍按上文执行。

### 8.1 光照与材质（针对“静止时大脑偏暗”）

| 项目 | Phase 3 | Phase 4 | 备注 |
|---|---|---|---|
| 皮层底色 | `#1d3247` | `#2a4a66` | 仍为暗蓝灰系 |
| 环境光 | 0.55 | 0.85 | 色温 `#bcd8ff` 不变 |
| 半球光 | 无 | 0.6（天 `#9fc8ff` / 地 `#0a1626`） | 新增，表现曲面起伏 |
| 主光 | 1.4 | 1.9 | 位置 `(80, 120, 160)` 不变 |
| 蓝 rim 光 | 0.5 | 0.7 | 位置 `(-100, -60, -80)` 不变 |
| 前下补光 | 无 | 0.45（`#dfeaff`，`(0, -100, 180)`） | 新增，提亮下半球 |
| 粗糙度 / 金属度 | 0.55 / 0.15 | 0.42 / 0.08 | 高光更易读 |
| 线框叠加不透明度 | 0.07 | 0.12 | 仍克制 |
| 背景 | `#05080C` | 不变 | 不加泛光、不加雾效 |

活动着色改为 CHIMERA 热色阶：底色 → 琥珀 `#ffb340` →
亮琥珀 `#fff8ec`，全部只由快照 E 决定（强度 ≤0.55 时底色→琥珀，
>0.55 时琥珀→亮琥珀）；禁止任何与模型无关的呼吸、闪烁动画。

### 8.2 默认视角与镜头

- 默认相机 `(0, 10, 285)` → `(75, 95, 245)`：右前上方微俯视，
  脑回深度层次比正顶视更易读；与目标距离相当，大脑仍为视觉中心。
- 双击背景 / RESET 恢复视角改为 600 ms 缓动飞行（easeInOutCubic），
  不是瞬跳。飞行期间关闭 OrbitControls 与自动旋转，起飞前直接清零
  拖拽残留动量（`_sphericalDelta` / `_panOffset`，three 0.187.0
  内部字段，已核对源码；不得用“无阻尼 update() 消耗”的做法，
  实测会把残留动量一次性全施加到相机上造成跳变）。
- 用户一旦 pointerdown 接手，飞行立即取消。

### 8.3 旋钮

- 表盘 44 px → 54 px；加 11 格刻度线（-135° ~ +135°，每 27° 一格，
  两端与中点加粗）。
- 新增滚轮调节（步进 0.02，Shift 加速 0.1），拖动、双击恢复默认、
  方向键微调保留；滚轮用原生非 passive 监听并 preventDefault，
  防止页面跟着滚动。
- 模型说明文字允许换行（此前 `white-space: nowrap` 在 1280 px 下
  曾把 CONNECTIVITY 的范围截掉）；四条说明统一带安全范围：
  幅度 0.5–2.0、脉冲 20–500 ms、c_ei 3–8、G 0–0.4。
  映射与安全范围本身不改（见模型规范 §8.7）。

### 8.4 波形图

- 横向网格：0.1 小刻度（淡）、0.2/0.4/0.6 主刻度、0 基线略亮；
  纵向时间网格每 2 s 一条，底部标仿真时间（秒）。
- 标题栏标注 `10 S` 窗口；E/I/BOTH 切换、事件竖线、暂停保留近期
  曲线、换脑区清空均保留；纵轴仍为任意单位，不标 EEG 电压。

### 8.5 触摸与性能

- 触摸：单指点选、单指拖动旋转、双指缩放/平移（OrbitControls
  `ONE: ROTATE, TWO: DOLLY_PAN`，显式声明）；点选与拖拽仍用 6 px
  位移阈值区分，与鼠标一致。
- 性能：颜色插值在静止后跳过整轮 16384×3 扫描；快照仍约 60 Hz，
  React 面板约 15 Hz；有界历史不变，无新增无界状态。
  真机 GPU 帧率与 10 分钟连续运行未在本机验证（见验证报告 §12）。
