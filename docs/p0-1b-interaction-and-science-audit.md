# BrainRun P0-1B · 实际控件作用、3D 手势与跨视图数值审计

**审计基线：** PR #10（`6be676e8`），在 PR #10 尚未合并时采取堆叠 PR 的形式；`main` 未直接修改。

**审计对象：** `docs/p0-1b-control-register.json` 登记 **19 个 React TSX 模块、212 个静态控件声明**；与上一批的 207 个不同，这次额外覆盖此前漏计的 `ParamControl` 和 `ActivityChart`。原生指针事件、3D 源拖动、滚轮事件是另一层入口，**不计入 212**。组件的 JSX 循环（例如 15 场景、76 脑区、E/I/BOTH）会产生多个运行时控件，不能用静态数量冒充用户看到的按钮总数。

## 1. 控件科学影响分级（静态模型边界，而非全部 E2E 已证）

| 审计标签 | 静态声明量 | 可影响什么 | 不能宣称什么 |
| --- | ---: | --- | --- |
| LIVE | 17 | Rust/WASM 网络时钟、权重、持续偏置、参数、快照 | 不意味着已更新 EEG Raw 或独立实验的分析 |
| SELECTION | 3 | React 选中的脑区，联动主 3D、REGION、ActivityChart 和细胞输入 | 选择 ≠ 刺激 |
| VISUAL | 16 | 色标、相机、回放显示与本地选择；不修改神经状态 | 动画变了 ≠ 物理计算变了 |
| NAV | 27 | 模态切换、模态打开关闭、实验台路由 | 打开实验台 ≠ 自动载入刚运行的场景 |
| INDEPENDENT | 69 | LIF/HH、多房室、局部 JR、MNE 球形/导体、逆问题、独立实验 | 不是同一全脑模拟的同步求解结果 |
| CONFIG | 45 | 配置算法、刺激参数、窗长、模拟噪声等 | 参数已经改了 ≠ 重新执行求解 |
| DERIVED | 13 | 对已有记录/试次做 PSD、ERP、TFR、地形等派生处理 | 不应凭标签页名字假定 Raw/epochs 同源 |
| MIXED | 17 | S1–S3 直播/S4–S15 独立场景、假设电流源、细胞 bias、感官定时刺激等 | 不具有已校准的人脑物理耦合关系 |
| EXPORT | 3 | 将当前数据下载/保存 | 不会改变神经动力学 |
| DIAGNOSTIC | 2 | 验证拒绝未配准 MNI152 与 Talairach 坐标 | 不会求出坐标转换 |

所有 212 条记录都要求 `controlId`、文件路径、源码行号、事件、模型边界与是否还需要运行验证。**源码事件绑定证明“接了 handler”，不证明“传到了求解器”**；请不要把登记文件当作 212/212 的浏览器验收。

## 2. 本轮修复的高确定性 3D 控件错误

| 操作 | 原先问题 | 预期与修复 |
| --- | --- | --- |
| 左键按下后拖动旋转 | `pointerdown` 就调用 `onSelect`，因此单纯转动视角会悄悄改变选中脑区；细胞直播输入、REGION 和活动曲线一起发生非物理的选择变化 | 延迟选区到**真正的完成点击或长按开始**；超过 6px 的旋转不改选区、不触发刺激 |
| 右键或辅助触点 | 原处理器未过滤非主按钮/次要触点，可能错误创建按住或刺激 | 右键、中键及次要指针只归 Three.js 相机控制，不进神经模拟输入 |
| `pointercancel/pointerleave` 后出现迟到的 `pointerup` | 原代码没有按压配对守卫，可复用旧的 `downRegion` 发假脉冲 | 无有效按下过程的 `pointerup` 直接忽略 |
| 从背景按下，松开时压在皮层 | 原来 `downRegion ?? pickRegion(up)` 可能把非皮层按压解释为脑区刺激 | 只接受按下时真的命中的皮层源区域 |
| 真正单击皮层 | 新规则不能误伤真实互动 | 点击选区 → Worker 脉冲 → 实际 E 峰值与响应窗口 → ActivityChart 同一脑区、同时钟、同数值 |
| 真正按住 | 不能改为仅视觉确认 | holdStart 同时选择脑区并输入连续神经刺激，直到松开/取消 |

`app/tests/p0-1b-browser-gestures.mjs` 在**真正的生产构建 + Rust/WASM + Three.js/SwiftShader 浏览器**里执行：旋转、右键、取消后松开、点击、射线命中、响应时间窗、3D/图表/REGION 状态一致、网络边权改动与恢复、持续偏置在真实引擎读回。这些是对外部行为的测试，不是直接调用求解器来伪装鼠标点击。

另补充 ActivityChart 的**只读诊断样本**：用 `t_ms` 对齐图表缓存与 SimClient 历史快照，要求 E 和 I 浮点值逐个相等，而不只是看图表是否“画出了线”。

## 3. 全部实验台的数据路径：每种控制到底改哪里？

| 用户可见实验台 | 真正计算路径 | 会刷新哪个视图 | 与 LIVE 主脑的限制 |
| --- | --- | --- | --- |
| PLAY 的刺激、背景、G、边权、偏置 | App → SimClient → Worker → Rust WC | LIVE 3D / REGION / RESPONSE / ActivityChart | **真实相同模型**；不会自动重新计算 EEG/ERP |
| 3D 的旋转、颜色、双击归位 | OrbitControls、Three.js | 仅相机、着色、显示元素 | **视觉操作**，不得产生脉冲或修改 E/I |
| EXPLORE 点脑区 | 统一 App.selectedId | 主脑选择、活动曲线、细胞直播输入 | 共享选区，**非物理刺激** |
| S1–S3 | 主 WC 网络后记录 RESPONSE 摘要 | 3D/RESPONSE 与场景数值 | 缺完整可重放实验会话 |
| S4–S15 | JR/HH/球形正向等独立函数 | 场景摘要（导航不载入原实验） | 没有共享 `runId`，不能直接说“与主脑同步” |
| LIF、HH、多房室 | 独立 RK/细胞求解器 | 当前细胞电位、发放率与通道电导 | 直播选区 E→电流是未经校准的假设；只有显式 dP→bias 按钮向主脑写入 |
| DIPOLE / HEAD EEG / LocalBEM | 解析无限导体 / MNE 球形 / 导入真实 BEM | 模态内部传感器电位 | 只有符合物理配置的独立求解；TVB → HEAD 空间**未配准** |
| 多导 EEG | 独立柱模型或约 60Hz LIVE 快照推导 | Raw / PSD 等派生图 | 直播近似记录**不是**原生 250Hz 电生理源采样，P0-3 阻塞 |
| ERP late | 独立 oddball 试次 | ERP、TFR | Raw/PSD/Topo 可能仍来自不同记录，P0-4 阻塞 |
| Topo 左、右 | 左：Raw 数据空间插值；右：手动源 L·q 的 2D 点位投影 | 两张示意图 | **不是同源 3D 头皮电位场** |
| Inverse | 独立真源盲测，或已有 Raw 的峰值点逆解 | 估计位置、残差、源分布 | 与主脑的真实源未注册；合成盲测不得泄漏真值 |
| TES/TMS、感官输入 | 均匀导体解析场/本地柱 + 若满足条件则向 LIVE 发脉冲 | 场实验局部结果与主脑 RECEPONSE | 增益和空间映射未校准；感觉序列由浏览器墙钟安排，非共享模型时钟 |
| A/B、时间机器、闭环 | JR 独立模型或 LIVE E 阈值轮询 | 对照实验台或主脑脉冲 | 并非真正的主脑 EEG 特征闭环；缺共同仿真时钟 |

## 4. 科学、数值与测试证据的边界

- `LIVE E/I` 是 Wilson–Cowan **无量纲神经群体活动**，不是头皮 EEG `µV`。
- 单独四层球形、BEM、Jansen–Rit、LIF/HH 测试只验证对应的数学模型或独立参考；没有凭此建立人脑多尺度一体化模型。
- 脑区 `TVB Demo 76` 的空间中心没有注册到 MNE HEAD/MRI，与源正向模型共享屏幕并不代表生理配准。
- 约 60Hz 快照线性插值到 250Hz 的直播记录，**不能虚构 30–45Hz 的真实信息**。
- 瞬时 E / E-RMS 阈值形成的直播闭环不是“EEG 闭环”。
- 浏览器与 MNE/TVB/Python/Rust 的科学基准应分别保留；本轮纯输入和视图逻辑修改绝不能改变生理参数或放宽容差。
- 出现工具、数据资产、内存、GPU 或权限故障，必须将状态表述为**未验证**，不得在视觉成功后直接判定为合并通过。
