# Brain Physics Playground — 模型规范（Model Spec）

版本：v1.0（Phase 1，规范先行；引擎实现在 Phase 2）
依据：`phase0-verification.md` 第 3 节（TVB 2.9 文档 + `tvb-library` 源码
`tvb/simulator/models/wilson_cowan.py` `dfun` 第 312–341 行实测）。
本文件只写已核实的方程与参数；未核实项明确标注，不猜。

## 1. 模型选型

Wilson–Cowan 兴奋性—抑制性神经群体模型（Wilson & Cowan 1972,
Biophysical Journal 12:1–24，方程 11、12）。

每个脑区由两个神经群体描述：兴奋性群体 E 与抑制性群体 I，
通过非线性微分方程演化，并经脑区连接网络相互作用。

定位声明（对外口径）：这是“基于神经生理机制的实时仿真”，
不是完整的第一性原理神经元物理仿真，也不是真实人类大脑全部
生物物理细节的模拟。E、I 状态范围 [0, 1]。
默认连接组是**演示用连接组（Demo Connectome）**：TVB 示例数据的
猕猴 CoCoMac + 人类 DSI 混合矩阵，不是某个真人的个体化连接网络；
TVB 官方声明该数据集“为数值测试与理论探索定制，生物物理真实性
有限，不应以此为依据”。模拟结果是模型在该演示连接组上的行为，
不代表真实人脑的客观反应。应用内「模型信息」与 README 有同样说明。

## 2. 方程（以 TVB 源码实测形式为准）

Sigmoid 响应函数：

```
S(x) = c / (1 + exp(-a · (x - b)))
```

单节点动力学（TVB `dfun` 实测形式）：

```
x_e = α_e · (c_ee·E − c_ei·I + P − θ_e + coupling_E + local)
x_i = α_i · (c_ie·E − c_ii·I + Q − θ_i + local)
S_e = c_e / (1 + exp(−a_e·(x_e − b_e)))
S_i = c_i / (1 + exp(−a_i·(x_i − b_i)))
dE/dt = (−E + (k_e − r_e·E)·S_e) / τ_e
dI/dt = (−I + (k_i − r_i·I)·S_i) / τ_i
```

关键点：
- **长程耦合只进入 E 方程**（耦合是外部输入 P 的入口，见 TVB 文档）。
  I 方程不含网络耦合项。
- `local` 为 TVB 的局部耦合项；MVP 默认实现中 local = 0（待 Phase 2
  对照源码确认后写入实现文档）。
- 标准教科书形式（Neuromatch 教程）为
  `τ_E dE/dt = −E + F_E(w_EE·E − w_EI·I + P)`，
  `τ_I dI/dt = −I + F_I(w_IE·E − w_II·I + Q)`，
  `F(x; a, θ) = 1 / (1 + exp(−a·(x − θ)))`；与 TVB 形式等价类，
  实现以 TVB 源码形式为准。

### TVB 文档笔误（已核实，写进实现时注意）

TVB 在线文档渲染的通用方程里，I 方程写的是 `c_ie·E_k − c_ee·I_k`，
与参数定义矛盾；**源码实测为 `c_ie·E − c_ii·I`**，以源码为准，
文档该处疑似笔误。实现时 I 方程的抑制自耦合系数必须是 `c_ii`。

另：文档 Table 0 列出 `shift_sigmoid = True`。该开关在 `tvb-library`
2.10.0 里存在且**默认 True**，会改变 sigmoid 使 S(0)=0；本实现
按 `shift_sigmoid = False` 的形式实现（与 TVB 官方对照
`docs/tvb-crosscheck.md` 一致）。旧版注记称源码无 `shift` 字样，
在 2.10.0 下已不成立，见 PR1 订正。

## 4. 网络规模与数据处理规则

- 节点数：76（TVB `connectivity_76` 配套数据，**演示用连接组**：
  权重主要来自猕猴 CoCoMac 示踪数据，胼胝体连接是人类 DSI 纤维束
  宽度缩放后填入的双半球混合矩阵，皮层下结构未包含；见 §7 与
  TVB 官方文档《A Description of a Complete Dataset》）。
- 连接权重 `C_ij`：`weights.txt`，76×76，值域 0–3，单位 au（任意单位，见 `info.txt`：`weights_unit = "au"`）。
  非零元 1560 个。值分布（本次预处理实测，纠正 phase0“全是整数”的说法）：
  5742 个值为整数 0/1/2/3，另有 34 个非整数值（如 0.0046263241、
  1.162475、2.4879251，均在 0–3 内，成对出现且成对值在第 7 位小数处
  略有差异）。权重以浮点原值保存，禁止取整篡改。
  这是粗粒度权重，不是连续纤维束计数/FA 值；是否归一化由 Phase 2 决定并记录。
- **权重对角线清零**：`weights.txt` 对角元最大 3.0（存在自连接权重），
  建模前必须把对角线清零，否则每个脑区会自己驱动自己。
  预处理脚本输出的权重矩阵即为清零后的版本；原始矩阵只保留在
  `scripts/prepare-brain-data/raw/`，不进仓库、不进前端资产。
- 传导延迟：`tract_lengths.txt`，76×76，值域 0–153.49 mm，单位 mm，
  非零元 5402 个，远多于权重的非零元（1560）。
  **延迟只对权重 > 0 的边生效**；权重为 0 的边即使有长度值也不产生延迟耦合。
- 脑区中心：`centres.txt`，76 行，含标签（如 rA1、rAMYG）与 xyz 坐标，
  与皮层网格同一量级（mm 量级，见 phase0-verification.md §1）。
- 皮层网格：`cortex_16384`，16384 顶点、32760 三角面；映射文件
  `regionMapping_16k_76.txt`，16384 个值，0-based，取值 0–75，
  76 个脑区全部出现，无未映射顶点（没有 −1）。
- 未核实：网格是否分左右半球存储、坐标系是 MNI 还是 TVB 自定义、
  法线是否已归一化；`connectivity_76` 原始出处与采集细节。
  实现时不得假装这些已核实。

## 5. 数值求解（Phase 2 实现要求，先写规范）

- 固定仿真时间步长，初始 1 ms 左右，再按稳定性测试调整。
- 优先采用经过验证的数值积分方案，例如 Heun。
- 用历史缓冲区实现脑区传导延迟。
- 支持确定性随机种子；参数修改通过明确事件提交。
- 支持暂停、继续、重置；支持检查模型状态是否发散（NaN / Infinity
  即判为非法状态，不得静默）。
- 输出可供前端读取的实时状态快照；渲染器只读物理状态，
  不得拥有第二套虚假活动生成逻辑。
- Rust 实现须与独立 Python 参考实现对照，在约定容差内一致；
  相同初始条件与事件序列必须重复产生相同结果。

## 6. 物理量 → 前端映射（Phase 3 接入，Phase 1 只留接口位置）

| 物理量 | 前端表现 |
|---|---|
| 兴奋性活动 E | 脑区活动亮度、曲线 |
| 抑制性活动 I | 可选的抑制状态读数 |
| 外部刺激 P | 刺激位置、输入强度标记 |
| 连接权重 C | 连接线的强度编码 |
| 传导延迟 d | 区域间响应的计算时间关系 |
| 模型时间 t | 仿真计时器、曲线时间轴 |

结构连接线可用视觉辅助表现，但粒子流动不能伪装成真实轴突电位传播，
除非其显示规则与模型的传导参数严格对应。
**禁止使用单独生成的随机活动动画冒充仿真结果。**

## 8. Phase 2 附录：已定死的数据口径与实现约定

（依据：`docs/validation.md` 全部实测数字；本节是 Phase 3 的契约。）

### 8.1 数据来源

全部实验与引擎输入使用 `app/public/brain-assets/connectivity.json`
（**演示用连接组**，见 §1 与 §4；权重与长度，对角线已清零、长度只
保留权重 > 0 的边、权重浮点原值、34 个非整数值不取整）。
不用 `scripts/prepare-brain-data/raw/` 的原始文件。
权重 76×76，值域 0–3（单位 au）；长度 76×76，值域 0–153.49 mm；
权重 > 0 的边 1494 条；权重矩阵不对称（有向）；有 2 个脑区入边行和为 0。

### 8.2 耦合定义（TVB 惯例，原始权重求和）

```
coupling_E_i(t) = G · Σ_j C_ij · E_j(t − d_ij)
```

- C 为原始权重，不做归一化。行归一化（均值场）已测试并否决：
  单节点传播在 G=4–8 时仍 < 0.005，且 G ≥ 6 时不再恢复基线
  （`docs/validation.md` §2）。
- G 为线性耦合斜率（TVB `Linear` 耦合的 `a`）。
  TVB 默认斜率在 2.10.0 下为 0.00390625（旧版注记 0.0042 已订正），
  是为静息态 fMRI 调的，在本配置下单节点传播不可见（实测），
  故演示用较大斜率。
- 长程耦合只进入 E 方程；I 方程不含耦合项；`local` = 0。

### 8.3 延迟

- 传导速度 v = **3.0 mm/ms**（TVB `Connectivity.speed` 默认值，
  源码 `tvb/datatypes/connectivity.py` L120–126 与 L522 实测）。
- `d_ij = length_ij / v`（毫秒）；步数 `idelay_ij = rint(d_ij / dt)`，
  四舍五入到最近整数、.5 向偶数舍入，与 TVB `set_idelays` 完全一致；
  权重为 0 的边 idelay=0（不用）。
- dt=1 ms 时真实边的 idelay 为 2–46 步；t<0 的历史读作初值。

### 8.4 数值积分

- Heun（预测—校正），固定步长，默认 dt=1 ms。
- 校正步的延迟读取：idelay ≥ 1 时用已提交的历史行；
  idelay=0 时用预测值（Python 与 Rust 逐操作一致，最大偏差 3.4e-16）。
- sigmoid 指数项钳制在 [−700, 700]，保证两实现逐字一致。
- 发散检查：任一状态非有限或 |E|,|I| > 1e6 时立即报错停住，不静默。
- dt 敏感性：dt=1 ms 相对 dt=0.5 ms 的最大偏差 6.3e-04；
  dt=2 ms 时 3.1e-03；二阶收敛。

### 8.5 噪声与种子

- 均匀白噪声，加在外部输入 P 上，幅度 `noise_amp`（默认 0=关闭）。
- RNG 为 SplitMix64（种子 0 的首个输出 0xE220A8397B1DCDAF，
  与定义一致）；每节点每求导一次按节点顺序抽取，
  预测步先于校正步；Python 与 Rust 的噪声轨迹最大偏差 5.6e-17。
- `noise_amp=0` 时 RNG 不使用，结果完全确定。

### 8.6 刺激与初值

- 外部刺激 `P_i(t)`：事件列表，`[start, start+duration)` 内幅度恒定，
  其余时间为 0；Q 恒为 0。脉冲与按住均为同一种事件（时长不同）。
- 初值：E=I=0（全部脑区），历史填初值；重置恢复该初值。
- 默认刺激：节点 40（lAMYG）、幅度 2.0（模型单位）、时长 100 ms。

### 8.7 参数：A-set（参考配置）与演示预设（产品默认）

**A-set（`Params()` 默认值，TVB 代码实际默认值）：**

| 参数 | 值 | 参数 | 值 |
|---|---|---|---|
| c_ee | 12.0 | c_ei | 4.0 |
| c_ie | 13.0 | c_ii | 11.0 |
| τ_e, τ_i | 10.0 ms | a_e | 1.2 |
| b_e | 2.8 | a_i | 1.0 |
| b_i | 4.0 | θ_e, θ_i | 0.0 |
| c_e, c_i | 1.0 | r_e, r_i | 1.0 |
| k_e, k_i | 1.0 | α_e, α_i | 1.0 |

**演示预设（`Params.demo()`，Phase 3 默认）：A-set + θ_e 0 → 1.0，
G=0.35，速度 3.0 mm/ms，dt=1 ms。**

改动原因（实测，见 `docs/validation.md` §1）：
A-set 单节点有三个不动点（低 E\*=0.073 稳定、中 E\*=0.127 不稳定、
高 E\*=0.475 稳定），幅度 ≥ ~0.1 的脉冲即永久锁死被点脑区，
网络耦合下级联翻转全脑，MVP 的“点击—响应—恢复—再点击”循环无法成立。
只改 θ_e 一个参数即可消除高不动点（唯一稳定点 E\*=0.011），
脉冲峰值 ΔE≈0.48、72 ms 内恢复、8/75 脑区瞬态响应、
500 ms 按住 18/75 脑区响应并恢复。
该预设是产品层面的选择，需用户确认；引擎不依赖它。

**实测稳定性边界（参数控件范围以此为准）：**

| 控件 | 默认 | 边界 |
|---|---|---|
| 连接强度 G | 0.35 | ≥0.5 时基线翻转到高态 |
| 刺激幅度（模型单位） | 2.0 | 1.0 以下几乎无响应；4.0 在默认 G 下仍安全 |
| 抑制 c_ei | 4.0 | 降到 2.0 时刺激翻转全网 |
| 按住时长 | — | ≤500 ms 安全；≥1000 ms 锁住网络（全网均值 E≈0.24） |

## 9. PR4：背景活动、振荡预设、实验快照、按住体验

### 9.1 背景活动三档

三档共用一个确定性随机种子（默认 0）：同一种子 + 同一参数，
活动序列逐值相同（Rust、Python、WASM 三方逐值对照，最大偏差
≤ 2.1e-15；同种子两次运行差 0.0，换种子则不同，reset 后重跑与
首次逐值相等）。三档关系见界面：背景是持续输入，偏置是用户对
选中脑区施加的持续输入，脉冲是一次性输入；三者叠加进同一个 P。

- **Quiet（安静基线）**：背景驱动为 0，行为与 PR4 之前完全一致。
  演示预设无白噪声（`noise_amp = 0`），故 Quiet 下平均 E 恒为
  0.0149（实测 10 秒，标准差 0.0）。
- **Spontaneous（自发，默认）**：每脑区兴奋输入加一个独立的
  Ornstein–Uhlenbeck 过程驱动。OU 方程（Euler–Maruyama，每步
  一次）：
  ```
  dx = -(x/τ)·dt + σ·√(2·dt/τ)·dW，τ = 100 ms，σ = 0.10（模型单位 P）
  ```
  OU 状态在引擎内、`step_one` 里每步推进一次——**绝不能放在
  `deriv` 里**，`deriv` 每步被 Heun 预测 + 校正调用两次，放进去
  会每步推进两次（Rust 单元测试 `pr4_ou_single_update_per_step`
  钉死此语义：两步恰好消耗 4 个均匀随机数）。OU 与白噪声共用
  同一个 SplitMix64 RNG、同一个抽取顺序；高斯抽取用 Box–Muller
  余弦分支，每抽取消耗恰好 2 个均匀数，u1 映射到 (0,1] 使 ln
  永不取 0。OU 状态进快照（§9.3）。
- **Oscillatory（振荡，外部驱动）**：见 §9.2。

**默认模式定法（实测决定，默认 Spontaneous，σ = 0.10）**。
三项安全检查，全部在真实 76 区网络上、三个种子（0/1/2）：
（a）空跑 60 秒仿真时间不锁死、不发散；
（b）标准脉冲（演示脑区 40，幅度 2.0，100 ms）在固定时刻后恢复；
（c）同一脉冲（脑区 40）在 8 个点击时刻（500–5000 ms）× 3 个种子上全部恢复。
另测双脉冲（点—恢复—再点）也恢复。

| OU σ | 60 秒空跑（最大平均 E） | 脑区 40 固定时刻脉冲 | 脑区 40，8 时刻 × 3 种子脉冲 | 节点活动标准差中位数 |
|---|---|---|---|---|
| 0.05 | 0.0155 安全 | 恢复 | 0/24 翻转 | 0.0010（太安静） |
| **0.10（默认）** | **0.0165 安全** | **恢复** | **0/24 翻转** | **0.0021** |
| 0.15 | 0.0178 安全 | 恢复 | **2/24 翻转**（全锁到 0.46） | 0.0032 |
| 0.20 | **锁死**（1.3–35.9 秒内，三个种子全锁） | 锁死 | — | — |

结论：0.20 与 0.15 均被实测否决——0.20 连空跑都锁死；
0.15 在固定点击时刻看着安全，但点击瞬间的 OU 状态决定结果，
换时刻就有 2/24 次点击把网络翻进高活动态（平均 E 0.46，
3 秒后仍在）。0.10 是三项检查全过的最大幅度，故为默认；
0.05 虽安全但活动太弱（节点标准差 0.0010），达不到“有生命感”。
Quiet 保留，一键可回。扫描脚本：
`reference/python-model/pr4_ou_60s_scan.py`、
`pr4_pulse_safety.py`、`pr4_pulse_timing.py`。

**翻转概率取决于被点脑区（重要限定）。**
上表只对演示脑区 40 成立。节点扫描
（`reference/python-model/pr4_pulse_nodes.py`，12 个采样脑区）：
σ=0.10 时脑区 69（lTCI）的脉冲翻转 6/12，脑区 73（lV1）翻转 0/12；
而 **Quiet 下（零背景）脑区 0/10/20/30/54/55/59/60 的标准脉冲
同样 2/2 翻转**，只有 40/47/69/73 恢复。也就是说，θ_e=1.0 只保证
单节点唯一稳定点，网络本身仍是双稳态——多数脑区的标准脉冲本来
就会把全网翻进高活动态，这是 PR4 之前就有的既有性质，不是背景
驱动造成的；背景只多加了一个边界脑区（69，Quiet 下安全、
σ=0.10 下约 50% 翻转，σ=0.05 下仍是边界 1/2）。因此默认模式的
安全标准按任务原文取“**一打开不锁死**”（空跑 60 秒不锁）加
“演示脑区点击可恢复”，而不是“任意脑区点击都不翻转”——后者
连 Quiet 默认也达不到。脉冲翻转是瞬时的、无法像按住那样提前
预警，恢复路径是锁定横幅上的 RESET（一键，见 §9.4）；按住导致
的锁定另有按住开始时的自动快照可一键恢复。

### 9.2 振荡预设：没有自发极限环，改用标注的外部驱动

参数扫描结论（`pr4_scan.py`、`pr4_scan2.py`、`pr4_scan3.py`）：
**本 Wilson–Cowan 参数族里没有稳定的自发极限环。**
16 + 17 组候选参数 × 9 组初值（E0, I0 ∈ {0, 0.3, 0.6}²），
有/无恒定驱动 P ∈ {0.2, 0.5, 1.0}，τ_i 放到 100、c_ee 放到 16、
c_ie 放到 20——单节点与 76 区网络（逐节点标准差也查过，排除
去同步节律藏在平均值里）全部收敛到不动点，标准差恒为 0.00000。
TVB Table 1 那套常被引用的“20 Hz 振荡参数”（Sanz-Leon 2014 /
Daffertshofer & van Wijk 2011）本身收敛到**高活动不动点**
（单节点 E\*≈0.32、网络平均 E\*≈0.49，接近锁定态），故不采用。

采用的替代方案（明确标注，绝不称自发节律）：演示预设 +
全脑同相 10 Hz 正弦外部驱动，幅度 0.30（模型单位 P）。
实测（`pr4_sine_scan.py`，76 区网络，G=0.35）：
平均 E 在 [0.0113, 0.0211] 之间振荡（峰峰值 0.0099，单节点
最大峰峰值 0.0125），FFT 峰值 10.00 Hz，60 秒最大平均 E 0.021
（远低于锁定阈值 0.15），脉冲叠加其上仍有完整响应
（峰值 |ΔE[40]| = 0.483，之后回到基线；四个正弦相位上点击
都恢复）。幅度边界：0.50 时脉冲锁死网络（平均 E 0.46 不回），
故取 0.30（留约 2 倍裕度）。正弦相位用绝对仿真时间
（`step_count · dt`），跨 `run()` 调用不重启相位。

### 9.3 实验快照（可恢复的实验状态）

快照内容（缺一不可，否则恢复后轨迹漂移）：
模型参数、全部 76×76 live 权重、偏置输入、仿真时间
（`step_count`）、随机种子与 RNG 状态、OU 状态、当前 E/I、
延迟耦合历史（`e_hist` + `hist_base`——只存当前 E/I 不够，
延迟项会读错历史）。恢复后状态与保存时逐值一致（差 0.0），
且恢复后继续跑的轨迹与“不恢复一直跑”的对照逐值一致
（Rust / Python / WASM 三方均测过）。

存储位置与有效期：
- **手动快照**：一个，存浏览器 localStorage
 （键 `brainrun.snapshot.manual.v1`），刷新、关闭重开、RESET
  后都还在；只有用户点“保存快照”才会覆盖它。
- **自动快照**：一个，只存 Worker 内存，按住开始瞬间自动存
  （恢复按钮用它）；**绝不覆盖手动快照**；RESET 会清除它。
  恢复快照时同时清除进行中的脉冲/按住与回放窗口。

实现注意：快照经 JSON 序列化（WASM 侧 `serde_json`），必须开
`float_roundtrip` 特性——默认的浮点解析器对个别值会差 1 ULP
（实测恢复差 3.47e-18），开特性后恢复差精确为 0。

### 9.4 按住体验：预警、锁定说明、点击/按住区分

- 预警：按住进行中且平均 E > 0.05（未锁定）时，界面出现琥珀色
  横幅，显示当前平均 E、离锁定阈值 0.15 还剩百分之几的进度条，
  文案写明“松开即停；如果进入高活动稳定态，可一键恢复到按住前”。
- 锁定：平均 E 持续 500 ms 超过 0.15 即判定锁定。锁定是**网络
  进入了新的稳定状态，不是软件卡住**——横幅原话写清这一点，
  并给“恢复到按住前”与 RESET 两个按钮，不藏在 RESET 里。
  双稳态本身保留：不隐藏、不偷偷重置、不伪造衰减。
- 点击与按住的区分（四层）：300 ms 静止按住 + 6 px 移动阈值
  + 定时器 + **时间戳撤回**——慢机器上主线程处理滞后，
  定时器可能在指针抬起事件被处理前先触发，误把一次短点击
  判为按住；PR4 补上时间戳撤回：抬起事件的时间戳与按下相差
  < 300 ms 时，撤回这次误判的按住并照常发脉冲。浏览器测试在
  20 倍 CPU 节流下覆盖：短点击仍发脉冲且不产生按住/自动快照，
  真正的静止按住仍在阈值后触发。
