## 用户明确的三个关键决策

1. **不要删除现有 Wilson–Cowan 引擎。** 它已有实际计算与验证基础，继续作为 BrainRun 的网络动力学模块；后续必须补充电生理源模型、头部正向模型和局部细胞级模型，才能实现不同层次的生物物理仿真。
2. **优先打通真正的电流源到 EEG 的物理链条。** 这是最有决定性的升级，也是把 EEG 图中各项研究能力连接起来的关键。MNE 的现有方法和工具可以支持这条技术路径，而不需要重新实现整个 BEM 和逆解算法体系。
3. **始终把 CHIMERA 式体验放在产品最表层。** 用户不应该为了研究 Alpha 波、ERP 或 EEG 容积传导，就先学习一整套科研软件操作。科学复杂性应该体现在内部求解器、模型参数和验证过程，而不是强加给首次使用者。

统一的产品判断标准：无论新增多少科学功能，用户始终能通过直接操纵三维大脑及相关物理对象，看见真实计算产生的变化；而且所有这些复杂功能，都不影响最初的简单、直观和流畅。

---

这次的目标定义为：在现有 BrainRun 的基础上，完成一个具有 CHIMERA 式直观操作、实时因果反馈、精美 3D 表现和极低使用门槛的完整脑科学物理建模平台。

这不是只修复当前 MVP 的问题，也不是仅仅增加 EEG、ERP、频谱等分析图表，而是补齐整个科学仿真系统。

最终必须实现的完整计算链条：真实解剖结构、脑区图谱和神经连接 → 神经元、神经群体与网络动力学 → 生物电流源与电生理活动 → 脑组织、颅骨与头皮中的电场传播 → 真实物理正向模型产生的模拟 EEG → 脑电频段 → ERP → 时频分析 → 头皮地形 → 皮层源定位 → 三维动态。

这条链条必须能够被用户直接操纵。例如，在 3D 头部内部移动一个电流偶极子，头皮电极的电位和地形图随物理计算改变；修改神经群体动力学参数后，模型振荡与频谱发生变化。

需要明确科学边界：我们能够建立真正由物理方程驱动、可验证的多尺度仿真，却不能保证一个简化模型完美重现真实人类大脑全部活动。本计划会以可测试、可复现的科学正确性代替无法量化的“完美”，同时对交互与视觉品质提出严格的完成标准。

已核对 MNE-Python 的现行正向建模、源仿真、ERP、时频和电极布局文档，以及 TVB 的神经群体模型说明。这些功能都有可用的科学计算基础，不需要从零发明整套算法。

# 第一部分：产品定位与不可妥协的设计原则

## 1. 产品定位

BrainRun 不应成为另一个操作复杂的神经科学专业软件。产品定位为：**Interactive Physics-Based Brain Playground**。

用户可以通过直接操纵三维生物结构、神经网络连接、电流源、电极以及动力学参数，观察仿真系统实时产生的活动、电位、振荡和空间变化。

- 对于普通用户，它是一个能够自由探索的大脑科学世界。
- 对于学生，它是一个能够直观理解神经科学和 EEG 形成机制的交互式教学平台。
- 对于研究人员，它是一个具备清晰模型假设、可重复实验和可验证计算结果的仿真沙盒。

这三类用户使用同一套科学计算核心，而不是三套不同的模拟程序。

## 2. 四项最高优先级原则

### P0-A：极低使用门槛

- 打开网页即可进入可操作的大脑。
- 默认不要求登录、安装软件、配置模型或上传数据。
- 不要求使用者了解神经动力学方程。
- 所有主要功能可以通过鼠标和触摸操作完成。
- 默认界面不堆放生僻术语和复杂参数。
- 复杂科学信息按照用户需求逐步展开。
- 提供可直接进入的预设实验。
- 每种操作有明确视觉提示和结果反馈。

目标是让没有相关知识的人也能在一分钟内完成一次有意义的科学探索。

### P0-B：真正的实时因果反馈

任何交互都必须遵循：用户输入 → 更新模型参数或边界条件 → 科学求解器计算 → 输出物理状态 → 更新 3D 画面、信号与仪表。

不允许独立于科学求解器生成神经活动动画。允许提供交互确认动画、镜头运动和视觉插值，但必须与计算出的生物物理活动明确区分。

### P0-C：精美且可信的 3D 表现

参考 CHIMERA 的精密实验仪器视觉语言：深色背景；高质量真实解剖网格；冷蓝色结构；琥珀色活动反馈；清晰的空间层次；精细材质、边缘光照与轻量发光；小型实时测量仪表；平滑而精准的交互动作。

禁止用过量粒子、强发光或任意形变掩盖低质量三维结构。

### P0-D：科学诚实性

必须区分：1. 解剖数据与真实几何。2. 神经动力学模型。3. 电生理源模型。4. 电磁正向计算。5. 信号处理与统计分析。6. 基于结果的视觉表达。这些环节不能互相替代。

模型能够产生类似 Alpha 的振荡，并不自动代表已经准确模拟了人类闭眼静息 EEG。模型能产生事件相关响应，也不自动意味着具有认知意义上的 P300 或 N400。所有科学模式应有模型来源、单位、假设、有效范围及限制。

# 第三部分：先修复现有 BrainRun

在增加新功能之前，必须解决已有系统中的基础问题。

## 3.1 保留已完成的部分

保留以下现有模块：Rust Wilson–Cowan 引擎；Heun 数值积分；Python 参考实现；76 区网络动力学结构；WebAssembly 和 Web Worker 架构；Three.js 大脑渲染；基础刺激事件；兴奋、抑制和连接参数控制；确定性测试；已有数值对照和自动化测试。不因新增高级功能而破坏这些基础能力。

## 3.2 修复与完善事项

### 现有默认模型过于静态

增加经过验证的背景驱动机制，同时保留当前安静基线作为独立模式。至少提供：Quiet（低活动稳定状态）、Spontaneous（有模型来源的自发背景活动）、Oscillatory（明确参数下的振荡状态）、Stimulated（施加可控外部输入后的状态）。不得为了让大脑看起来活跃而添加与模型无关的随机闪烁。

### 网络响应过于短暂

增加：刺激前后变化视图；模型计算结果的时间缓存；慢动作回放；远端响应的独立色阶；清晰的刺激事件标记；当前响应最明显区域的可选提示。不改变底层响应时序来制造更好看的传播动画。

### CONNECT 尚不能真正修改连接

扩展 Rust API，使其支持修改单条网络边的权重，必要时重建延迟结构。用户能够直接选择和调整连接，恢复原值，并重新进行实验。

### 长按导致模型进入高活动稳定状态

新增安全探索参数预设、模型状态提示和明确的恢复操作。不隐藏双稳态等真实非线性现象，但确保初学者能够轻松恢复实验。

### 视觉、加载和性能问题

验证 WASM 加载期间不会丢失点击；测试 Apple Silicon 实际 GPU 性能；优化着色更新和不必要的内存分配；补充低画质模式；优化较小屏幕；测量连续运行稳定性；建立真实设备性能报告。

### 科学数据

继续落实已经合并的 PR #1。当前 TVB 示例连接组保留为 Demo Connectome，不将其描述为经过个体化验证的人脑连接组。新增的人类脑图谱、结构连接和电生理正向模型应使用互相匹配且来源清晰的数据。

# 第四部分：统一科学仿真架构

整个系统采用六层结构。

```
USER INTERACTION
触碰 / 拖动 / 旋钮 / 实验配置
           │
           ▼
ANATOMY & COORDINATE SYSTEM
解剖结构、脑图谱、源空间、电极空间
           │
           ▼
NEURAL DYNAMICS
神经元 / 神经群体 / 网络耦合
           │
           ▼
BIOELECTRIC SOURCE MODEL
突触后电流 / 等效电流偶极子
           │
           ▼
ELECTROMAGNETIC FORWARD MODEL
头部电导率 / BEM / FEM / Lead Field
           │
           ▼
SYNTHETIC EEG & EVENT DATA
连续 EEG / 事件 / 多试次
           │
           ▼
SCIENTIFIC ANALYSIS
ERP / PSD / TFR / Topography / Inverse
           │
           ▼
3D REAL-TIME PRESENTATION
三维脑、头皮、电极、波形、可视化
```

所有显示模块订阅同一个具有时间戳的仿真状态。

## 4.1 统一数据模型

至少需要定义：

- **AnatomyState**：解剖模板；脑图谱版本；皮层网格；头部组织网格；连接矩阵；坐标变换；电极布局；模型与资产标识。
- **NeuralState**：神经元或脑区状态；兴奋、抑制活动；电生理状态；网络耦合状态；外部输入；仿真时间。
- **SourceState**：电流源空间坐标；源方向；电流偶极矩；源时间序列；源与神经模型的映射方式。
- **EEGState**：电极位置；EEG 正向矩阵；参考方式；头皮电位；噪声参数；采样率。
- **ExperimentState**：模型版本；初始状态；参数变化；刺激事件；随机种子；快照；实验记录。
- **AnalysisState**：试次；ERP；频谱；时频结果；地形图；源定位结果。

不同模块不能各自维护互相矛盾的模型时间和物理状态。

# 第五部分：神经动力学与生物物理引擎

## 5.1 全脑神经群体模型

保留 Wilson–Cowan，并增加 Jansen–Rit 及经过验证的其他模型。不同模型承担不同用途。

**Wilson–Cowan** 用于：兴奋与抑制相互作用；网络传播；参数与稳定性探索；振荡与同步；脑区连接修改。

**Jansen–Rit** 用于：皮层神经群体电活动；有生理意义的振荡预设；突触后电位相关的状态变化；经过验证的诱发电位模型。

不能简单地把两套模型中同名或相近的变量视为同一物理量。

## 5.2 脑电节律模型

必须支持常见节律的探索：Delta、Theta、Alpha、Beta、Gamma。用户能够查看：当前模型振荡的主要频率；时域活动；功率谱峰值；频段功率；不同脑区的振荡关系；参数变化引起的频率和振幅变化；相位同步与网络耦合。

实现方法必须以真实动力学模型为基础。不能通过为每个波段指定一个正弦波并叠加，就声称实现了生理机制层面的节律生成。允许设置纯正弦输入作为教学实验，但必须标注为外部驱动信号，而不是自发脑电节律。

## 5.3 神经元级电生理

建立独立的局部神经元实验引擎。最少支持：Leaky Integrate-and-Fire；Hodgkin–Huxley；具有真实形态的多区室神经元示例；突触后电流；兴奋性和抑制性突触；动作电位发放；电流注入；膜电位和离子电导曲线。

可以使用 NEURON / NetPyNE 作为科学参考或计算后端，实时交互部分采用适合的局部模型。**多尺度模式不得只是视觉放大。** 放大到神经元层时，系统需要切换到明确的细胞级仿真模型；若与全脑模型联动，则必须定义跨尺度耦合和边界输入。

## 5.4 科学验证

每个动力学模型必须完成：1. 与参考实现对照；2. 固定点与稳定性分析；3. 参数扫描；4. 步长收敛；5. 噪声与随机种子测试；6. 刺激响应测试；7. 网络耦合因果测试；8. 长时间运行数值稳定性测试；9. 与可用实测数据进行适用范围内的对照。不允许仅以视觉上产生期望现象作为验证依据。

# 第六部分：真正的 EEG 生物物理正向仿真

这是整个升级计划中最关键的科学模块。

## 6.1 真实头部物理结构

建立能够用于 EEG 正向建模的标准人类头部模型。至少包含：皮层表面；头皮表面；颅骨相关边界；脑组织导电区域；电极几何位置；皮层源空间。首个物理模型建议使用 MNE-Python、fsaverage 及与其一致的头部 BEM 模型。

可视化可以额外显示脑脊液、灰质、白质等组织，但需要区分**展示用解剖分层**和**计算时实际参与的导电组织模型**。进一步提供包含更多组织分区的 FEM 模型，并比较不同电导率与组织分层对电场分布的影响。

## 6.2 神经活动到电流源

必须单独建立电生理源生成模块。例如，将具有明确生理含义的突触后活动，经过经过说明的等效偶极子模型映射为电流偶极矩。源至少需要：空间坐标；方向；幅度；时间序列；物理单位；所属皮层区域。

同时提供一个独立的**可操纵偶极子实验模式**，允许用户直接设置物理源。这是验证 EEG 正向模型最清晰的入口，也可以在尚未完成所有神经群体到电流源映射时，先建立真实的电磁物理演示。不能把无量纲的 Wilson–Cowan E 值直接当成微伏 EEG。

## 6.3 头部容积传导

使用准静态电磁近似建立 EEG Forward Model。核心计算：V(t) = L·q(t) + ε(t)。

要求：Lead-field 由真实定义的几何与电导率模型计算；电极与源空间配准一致；单位明确；参考电极变换正确；多电流源线性叠加正确；噪声模型独立可配置；可以比较球形头部、BEM 和 FEM 等不同近似的结果。

## 6.4 实时物理计算策略

不能在浏览器每一帧都重新求解一个大型 FEM 问题。采用：**离线 Python 科学预计算 + 浏览器实时 Rust/WASM 求值。**

预计算：源空间；几何变换；正向矩阵；预定义电极位置；部分可供交互选择的头皮采样点。

实时计算：电流源参数更新；电极电位；多导 EEG 时间序列；地形图对应电位；必要的矩阵求值。

移动电极时，优先使用在已验证几何模型上的可用头皮采样位置和受约束插值。超出预计算支持范围时，必须重新生成正向解或明确提示近似限制。

## 6.5 验收实验

必须完成：单偶极子仿真；双偶极子叠加；改变源方向；改变源位置；改变源强度；改变电极位置；改变参考方式；改变组织电导率；比较不同头部模型。同一场景的结果必须与 MNE-Python 科学参考实现进行数值对照。

最终用户能够做到：**拖动一个大脑内部的电流源，实时看到整个头皮的电位分布改变。** 这是必须重点打磨的 CHIMERA 式交互体验。

# 第七部分：标准 EEG 电极系统

## 7.1 完整支持的系统

必须提供：International 10–20；International 10–10；International 10–05；常见 32、64、128 导联预设；自定义电极组合；有物理位置约束的电极调整。默认电极模板与对应头部模型必须匹配。

特别注意：MNE-Python 在 1.13 版本调整了部分 montage 名称，不能长期硬编码已经变更的 API 名称。应锁定依赖版本，并通过自动测试检查标准电极名称与位置。

## 7.2 三维交互

用户选择 EEG 模式时：1. 皮层外出现半透明头部；2. 根据所选标准布局显示电极；3. 电极名称可按需显示；4. 点击电极显示其电位曲线；5. 切换电极系统后重建对应传感器配置；6. 拖动可移动的电极，查看空间采样变化；7. 切换参考方式并查看信号变化。如果新的电极配置需要重新计算正向模型，界面必须明确反映模型更新过程。

## 7.3 验收要求

电极坐标与参考模板一致；左右半球位置正确；Cz、Pz、Oz 等关键位置正确；电极与头部表面几何对应；不出现电极穿入颅骨或悬浮在头皮外的异常；电极名称及位置可导出；对应电位来自 EEG 正向模型。

# 第八部分：完整 EEG 信号与频域分析

## 8.1 连续 EEG

从实时正向模型中生成连续多导联 EEG。支持：250、500 Hz 等采样率；可配置记录时长；电极选择；参考方式；模拟噪声；工频干扰；基线漂移；眼动与肌电等独立标注的模拟伪迹；多导联波形显示；原始数据导出。伪迹必须有独立的生成逻辑和记录，不得被误标为神经源活动。

## 8.2 PSD 和频谱

至少实现：FFT；Welch PSD；相对功率与绝对功率；各频段功率；频谱峰值；频率分辨率与窗长控制；选定时间段分析；多导联频谱对比。用户选择一个电极后，可以从该电极的实际模拟时间序列计算频谱。不得将神经群体振荡曲线的 PSD 与头皮 EEG 的 PSD 混为同一物理测量对象。

## 8.3 振荡交互

用户能够：改变神经群体参数；改变刺激频率；改变连接强度；观察频率峰值变化；比较刺激前后频谱；查看不同脑区和电极的振荡；探索相位同步。预设可命名为「探索 Alpha 振荡」「观察 Theta 活动」等。这些预设必须绑定已验证的模型参数与预期频率范围。

---

# 第九部分：ERP 及事件相关实验

## 9.1 基础事件系统

建立统一的刺激事件管理：时间戳；事件类型；目标脑区或输入通道；刺激强度；持续时间；试次编号；模型参数快照。时间戳必须在仿真时间轴上精确定义，不能只在前端用浏览器墙钟近似记录。

## 9.2 ERP 计算功能

必须支持：单试次 EEG；事件锁定分段；基线校正；多试次平均；单试次叠加；不同条件的 ERP 对比；峰值振幅；峰值潜伏期；时间窗平均振幅；ROI 电极平均；置信区间或试次变异性展示。用户能够直接比较单次波形与多次平均后的结果。

## 9.3 ERP 预设实验

提供：单次刺激响应；重复刺激；不同刺激强度；不同刺激间隔；两条件对照；噪声对 ERP 平均的影响；P2 等简单诱发响应特征的探索；N200、P300、N400 等高级教学或模型实验。对于 P300、N400 等认知 ERP，必须有相应的任务和神经生成模型，或者明确标注为教学性合成示例。禁止通过直接添加固定的 P300 波形来宣称物理模型自动产生了认知加工。

## 9.4 验收

以同一组底层模拟试次为输入，BrainRun 的分段、基线和平均结果需要与 MNE-Python 参考实现达到约定误差要求。必须验证事件顺序、试次数量、边界处理及噪声影响。

# 第十部分：事件相关时频分析

## 10.1 方法

至少支持：STFT；Morlet 小波；Multitaper；事件相关功率变化；基线归一化；ERSP；ITC；诱发功率与非相位锁定活动的区分。

## 10.2 可视化

提供：时间 × 频率 × 功率热图；单电极时频图；多电极对照；指定频段功率随时间变化；用户选择时间—频率区域；反向关联三维电极位置；不同刺激条件的时频差异。

## 10.3 科学要求

明确：频率单位 Hz；时间单位秒或毫秒；功率单位和归一化方式；频率分辨率；时间分辨率；边界效应；基线时间段；有效试次数。不同方法计算的结果不能未经说明直接比较。

# 第十一部分：二维与三维 EEG 头皮地形图

## 11.1 2D Topography

用户能够选择：某一时间点；某个时间窗口；某个频段；ERP 峰值；不同条件的差异。系统将电极数据进行空间插值，绘制二维头皮地形图。

## 11.2 3D Scalp Potential

在真实头皮网格上显示计算得到的电位分布。用户可以：旋转头部；改变电流源；选择电极；查看不同时刻的电位；观察正负电位分布；比较不同参考方式；控制色标；观察刺激后的动态变化。

## 11.3 物理正确性

必须明确区分：**头皮电位场正向计算结果**与**有限数量电极的插值地形图**。两者可以显示相似的空间分布，但方法来源不同。不得把插值图称为完整的三维电磁场有限元求解结果。

# 第十二部分：Brain Atlases 与坐标系统

## 12.1 支持的空间体系

至少包括：Head Coordinates；MRI Native Coordinates；MNI 标准空间；Talairach 空间；fsaverage 表面空间；各脑图谱自带的原始空间。

## 12.2 脑图谱

首批目标：Desikan–Killiany；Destrieux；Schaefer 分区；Harvard–Oxford；AAL；Brodmann Areas；必要时增加其他有可靠来源的解剖及功能分区图谱。每个图谱必须标注数据来源、空间、分辨率、许可和版本。不强制将所有图谱直接用于同一神经动力学网络。显示分区、模型计算分区和源空间可以不同，但必须存在明确映射。

## 12.3 坐标交互

用户点击三维大脑任意有效位置，能够查看：当前原始坐标；MNI 坐标；如有可靠转换，则提供 Talairach 坐标；所属图谱脑区；对应脑区名称；左右半球；坐标转换方法。当无法确定转换时，显示「未配准」而不是编造坐标。MNI 与 Talairach 坐标之间的转换应标明使用的算法、模板及近似误差。

## 12.4 配准与一致性测试

必须检查：左右方向；轴方向；坐标单位；模板标识；fiducials；变换矩阵；逆变换；曲面和体积图谱之间的映射；电极与头部表面的配准。这部分直接关系到 EEG 正向与逆向建模的科学可信度。

---

# 第十三部分：EEG 皮层源定位

## 13.1 逆问题模块

支持至少两种源定位方法：Equivalent Current Dipole Fitting；Minimum Norm Estimates。并逐步提供：dSPM；sLORETA / eLORETA；源空间可视化；源时间序列；噪声协方差；逆算子配置。具体算法以 MNE-Python 中经过验证的实现为参考。

## 13.2 最有价值的交互

采用 Ground Truth vs Estimated Source 模式。用户将一个已知物理电流源放在三维大脑中：1. 正向模型计算 EEG。2. 用户观察头皮电位。3. 运行逆解。4. 三维大脑显示估计的源位置或分布。5. 比较实际源与估计源的差异。

需要显示：空间定位误差；源分布范围；不同算法的结果；不同电极数量；不同噪声水平；不同正则化参数。源定位是非唯一问题，不得把估计结果描述为真实源的唯一正确位置。

## 13.3 验收

必须在不向逆解算法泄露真实源标签的前提下完成盲测，并报告定位误差及不同条件下的表现。

# 第十四部分：更丰富的直接物理交互

这是让 BrainRun 真正达到 CHIMERA 式体验的关键。

## 14.1 Touch Brain

用户点击、按住、连续刺激某个脑区。必须有：精确位置反馈；生物物理模型响应；神经活动可视化；传播延迟；实时波形；可逆的实验状态。

## 14.2 Change a Connection

直接选择连接，调节网络耦合权重。实时观察模型状态与连接改变的关系。可以通过可视化控制点改变权重，但不得把控制点的空间位移误认为真实轴突长度的改变。

## 14.3 Move an Electrical Source

拖动电流偶极子的位置和方向。实时重新计算 EEG 正向投影。这是整个产品必须具备的核心演示。

## 14.4 Move an Electrode

在物理有效的头皮位置移动电极。观察该位置的电位如何随源位置和参考方式变化。

## 14.5 Change Oscillation Parameters

直接调整具有物理含义的神经群体参数。观察振荡频率、功率谱和脑区活动改变。

## 14.6 Change Tissue Conductivity

在高级实验模式中改变头部组织的电导率。必须根据当前计算方法重新计算或选择相应的正向模型，不允许只是改变视觉颜色。

## 14.7 Layered Anatomy

支持：隐藏头皮；隐藏颅骨；显示皮层；显示脑沟与脑回；选择脑区；剖切观察；显示电极；显示源空间；显示网络连接。剖切、透明度和分层显示属于可视化操作。只有真正影响模型边界条件的操作才进入物理求解器。

# 第十五部分：高级实验功能

## 15.1 双脑对照

创建 Brain A 和 Brain B。两者使用：相同初始状态；相同模型；相同随机种子；相同输入事件。用户只改变其中一个条件。能够比较：脑区活动；振荡；EEG；PSD；ERP；网络响应；源定位结果。支持同步旋转和同步时间轴。

## 15.2 时间机器

实现：暂停；单步运行；历史缓冲；回放；慢动作；恢复模型快照；修改参数后从历史状态重新运行；不同实验分支比较。所有回放均来自真实保存的模型状态或确定性重新计算。

## 15.3 感觉输入实验室

提供具有明确神经模型的输入场景：周期性视觉刺激；简化听觉刺激；重复刺激；不同输入强度；不同事件间隔；其他有相应通路模型的感觉输入。外部输入必须有明确的神经编码或输入映射。不能把「播放一段声音」直接等同于准确模拟听觉皮层真实反应。

## 15.4 脑刺激实验室

按物理完整性分级：

- **Level A：直接神经模型输入**——不声称是完整的 tES 或 TMS 物理刺激。
- **Level B：TES 电场**——利用有限元或其他适当物理方法计算电极配置产生的电场，并提供电场分布的 3D 交互演示。
- **Level C：TMS 电磁场**——使用适合的线圈、感应电场计算及组织模型。
- **Level D：电场到神经响应**——将电场通过经过验证的刺激—神经响应模型连接到神经动力学系统。

不能把某处电场强就直接解释成真实大脑必然发生兴奋或抑制。

## 15.5 闭环控制实验

用户可以配置：模拟 EEG → 特征提取 → 状态判定 → 控制器 → 虚拟刺激 → 神经响应。支持：固定阈值控制；PID 或其他明确控制策略；状态反馈；延迟；噪声；控制器开关；与无控制条件对照；误触发率、响应时延和稳定性分析。初版闭环仅用于模拟环境，不直接控制人体设备。

# 第十六部分：完整用户体验设计

## 16.1 不增加复杂主页

所有功能围绕同一个主三维场景展开。建议保留四个主要模式。

- **PLAY**（默认模式）：用户直接触碰大脑、施加输入、改变参数、观察网络响应。
- **WAVES**：探索振荡、脑电频段、功率谱和神经动力学。
- **EEG**：探索头部物理模型、电极、EEG、ERP、时频、地形和源定位。
- **EXPLORE**：探索解剖、脑图谱、标准坐标以及多尺度神经元模型。

高级的刺激场、闭环和对照实验可以通过模式内实验菜单进入，避免初次使用时出现十几个一级入口。

## 16.2 渐进式功能展示

默认只展示：一个占主要空间的 3D 大脑；少量控制；一个实时测量窗口；简单的操作说明。用户点击「更多」后，才出现：具体参数；数学模型；单位；频段设置；电极参考；源定位算法；模型假设。

## 16.3 一键科学场景

必须内置下列直接可玩的场景：

1. 触碰大脑，看网络如何响应。
2. 改变一条连接，看传播有何不同。
3. 改变兴奋／抑制参数，观察振荡。
4. 产生并观察 Alpha 等模型节律。
5. 移动电流源，看 EEG 如何变化。
6. 从 10–20 切换到 10–10 和 10–05。
7. 移动 Cz 附近的电极，看测量如何变化。
8. 重复刺激，观察 ERP 平均。
9. 查看时频图中的功率变化。
10. 比较头皮地形图和真实电流源位置。
11. 运行源定位，比较估计和真实位置。
12. 在两个大脑中进行单参数对照。
13. 进入神经元层面，注入电流观察动作电位。
14. 比较不同组织电导率的正向计算。
15. 构建一个简化 EEG 闭环控制实验。

每个场景都应提供可运行的模型预设、必要资产和实验记录。

## 阶段依赖关系

PR-04、PR-05、PR-06 是 EEG 物理仿真的关键路径。没有统一几何、坐标和源空间，不能认定 EEG 正向模型已经完成。

PR-06、PR-07 是 ERP、时频、头皮地形和源定位共享的数据基础。不能分别写几套毫不相关的模拟波形来提前宣称后续功能完成。

PR-13 至 PR-15 可以在基础 EEG 体系稳定后并行推进，但每个模块必须有可执行的物理或神经动力学模型。

# 第十九部分：正式验收标准

整个项目的最终交付必须同时通过五个验收维度。

## A. 数学与数值正确性

- Rust 与科学参考实现对照通过；
- 固定步长数值稳定；
- 参数单位正确；
- 相同种子与实验事件可复现；
- 网络耦合与延迟正确；
- 物理状态无静默 NaN/Inf；
- 前向模型与 MNE 结果一致；
- 信号处理算法与参考实现一致；
- 模型版本变化有回归测试。

容差必须按计算精度、输出量纲和算法定义设定，不能为通过测试而随意放宽。

## B. 物理和生理有效性

- 神经动力学具有合理的模型来源；
- 振荡特征符合其对应模型机制；
- 电流源具有空间位置、方向与单位；
- 电导率和头部几何参与正向计算；
- 计算出的 EEG 对源位置、方向和参考方式有正确响应；
- 真实数据对照范围明确；
- 逆问题结果带有误差和不确定性；
- 不将现象学模型的结果宣传为完整人类脑活动预测。

## C. 功能完整性

必须逐项通过第二部分的功能矩阵。任何标记为已实现的功能都需要：1. 实际可用的用户交互；2. 真实执行的计算路径；3. 可重复的最小实验；4. 自动化测试；5. 用户可见的结果；6. 相关方法与限制说明。只有按钮、空页面、预览图片或 TODO 接口，不算实现。

## D. CHIMERA 式体验

必须进行真实用户测试。测试对象包含不了解神经科学的参与者。主要验收任务：无教程完成第一次刺激；看懂刺激与神经响应的区别；通过调整参数发现变化；移动电流源并观察 EEG 改变；识别电极与脑区的空间关系；完成一次简单 ERP 或频段实验；在不理解公式的情况下完成一次双条件比较。

对任务完成率、首次操作时间、误操作率、主观理解程度和交互响应进行记录。建议目标：至少 80% 的首次使用者能够在无人员协助的情况下完成核心基础探索任务；具体阈值可在首次用户研究后收紧。

## E. 工程与发布质量

- macOS Chrome / Safari 实测；
- Windows 主流浏览器实测；
- 平板触摸操作实测；
- 首屏加载目标达成；
- 无严重布局错位；
- 无高频操作导致的白屏；
- 无显著长期内存泄漏；
- 失败时有明确诊断；
- 第三方数据授权明确；
- 代码许可证完整；
- 关键数据、模型和实验可复现；
- CI 对科学、交互和构建进行自动化检查。

# 第二十部分：一个完整的最终演示应该是什么样

当所有 PR 完成后，必须能够录制以下不经剪辑的连续演示。

- **演示一：触碰大脑**——打开网页，大脑立即可操作。点击运动皮层，模型产生局部响应，网络活动与波形同步变化。用户调节连接强度后再次刺激，结果发生可解释的变化。
- **演示二：探索 Alpha 振荡**——进入 Waves。选择经过验证的 Alpha 振荡模型预设。用户改变相关动力学参数，观察时域波形、频谱和主要振荡频率的改变。
- **演示三：从脑内电流源到头皮 EEG**——进入 EEG。显示半透明头部、电流源和标准 EEG 电极。用户拖动电流源，调整方向与幅度。EEG 波形和头皮电位图根据同一正向模型实时更新。
- **演示四：比较电极系统**——依次切换 10–20、10–10、10–05。显示标准电极位置、名称和可用的信号。选择 Cz、Pz、Oz，观察不同位置对同一电流源的测量差异。
- **演示五：从 Raw EEG 到 ERP**——重复施加时间锁定刺激。生成多次试次。显示单试次 EEG、事件标记、分段和平均结果。随着有效试次数变化，ERP 及其不确定性按照实际数据计算更新。
- **演示六：时频与地形**——对同一组 EEG 进行 PSD、时频与头皮地形分析。用户选定一个时间和频率范围，观察对应的电极功率或空间分布。所有图表均来自同一份信号与事件记录。
- **演示七：源定位**——在 3D 大脑内放置一个已知电流源。正向模型生成模拟 EEG。运行源定位算法。显示估计位置与已知源的差异，报告空间误差。
- **演示八：脑图谱和标准坐标**——切换多个图谱。点击同一个解剖位置，查看不同图谱的分区信息与明确配准后的坐标。展示 MNI/Talairach 转换来源和近似性质。
- **演示九：进入神经元内部**——从全脑放大到一个局部神经回路。运行细胞电生理模型。向神经元注入电流，观察膜电位、动作电位和突触响应。
- **演示十：完整对照实验**——创建两个相同模型。只改变一个参数。同时比较三维响应、神经活动和 EEG。回放、重置、重复实验并导出结果。

# 第二十一部分：AI 开发 Agent 必须遵守的工作流程

所有开发任务统一采用：**Inspect → Implement → Test → Validate → Visual Review → Regression → Merge**

1. **Inspect**：每次开始前检查仓库当前状态、已有功能、正在进行的 PR、测试和科学文档。不得凭旧 Plan 假设代码没有变化。
2. **Implement**：优先复用成熟科学库及经过验证的模型。不得为了减少开发工作而将物理计算改成纯视觉演示。
3. **Test**：每增加一个模块都要补充针对性的自动化测试。除正常输入，还应覆盖边界参数、异常数据、坐标不匹配、数值发散和浏览器交互问题。
4. **Validate**：将计算结果与独立参考实现进行对照。数值验证与生理验证分开报告。
5. **Visual Review**：检查真实截图和交互过程。重点检查：视觉质量；操作反馈；3D 解剖正确性；电极与模型位置；图表单位；数据显示一致性；低门槛使用体验。
6. **Regression**：重新运行此前已经通过的核心实验。任何新模块都不得悄悄破坏已有的神经动力学、EEG 正向或基础交互。
7. **Merge**：只有所有阻塞性测试通过、科学限制明确记录、可视化真实可用后，才能合并。不得通过修改测试期望值、删掉失败场景或放宽科学要求来制造通过结果。

# 第二十三部分：最终产品验收定义

BrainRun 2.0 的最终完成条件不是「所有菜单都能打开」，而是：

**每一个被称为物理仿真的功能，都有真实运行的模型、明确的计算链条、可信的输入输出和独立验证。**

**每一个可视化模块，都能从真实模型状态或真实计算结果中追溯其数据来源。**

**每一个主要交互，都应让非专业用户能够通过直接操纵三维对象来理解原因和结果。**

**所有高级科学功能，都不能破坏首页打开即玩的低门槛体验。**

最终希望用户能够像在 CHIMERA 中操纵声道、听见声音变化一样，在 BrainRun 中直接改变神经系统模型、电流源、连接和电极位置，实时观察神经活动、振荡、头皮电位以及相应的分析结果。这才是 BrainRun 完整版的最终交付标准。
