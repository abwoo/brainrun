# Manual physics workbench and complete interface language correction

The default surface is a directly manipulable physical model, not a preset launcher. The four-layer head-conductor model is embedded as the primary workbench. Source position, orientation and moment call the existing MNE forward projection; the 3D sensors and voltage readings consume those same results.

The secondary network tab separates selection from stimulation. Its strength and duration controls send actual SimClient parameter commands; the explicit input button sends the stimulus. Region selection and orbit gestures do not write inputs. Advanced analysis is behind the Advanced labs menu. Presets occupy a separate page and never open over the default model.

UI foundations: shared native Dropdown, labeled ControlField, bounded range/number control, and a persistent two-button language switch. The switch remains usable inside advanced labs. Full-message and parameterized catalogs replace sentence assembly from translated subwords. Technical identifiers and exported data remain stable.

README.md is English-first and links to README.zh-CN.md. Neither contains the removed product-style claim.

Acceptance uses the existing GitHub cloud gates and one combined browser flow: linear voltage response to source strength, source position/orientation changes, Worker-confirmed network input, state preservation across languages, screenshots in Chinese/English/mobile, all advanced text surfaces, shared-run JSON export, and nonblocking preset navigation. Screenshot review complements numerical assertions; passing a source scan alone is not a usability claim.
