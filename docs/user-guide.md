# BrainRun 用户指南（给非专业用户）

> 这是一份给第一次打开 BrainRun 的人的指南，不用懂公式也能玩。
> **先记住一句话：这是一个教学仿真，不是真的大脑。**
> 你在这里看到的一切波形和数字，都是一个简化数学模型算出来的演示，
> 不是某个真人的脑电，也不能用来判断健康、诊断疾病。
> 完整的科学说明见 `docs/model-spec.md`（§1 定位、§13 已知限制）。

## 1. 打开：你会看到什么

打开 https://abwoo.github.io/brainrun/（本地运行见 README），
屏幕中间是一个 3D 大脑，旁边有波形图和几个滑杆。
大脑默认在慢慢活动（这叫“自发”背景活动），波形在走——
那是模型在算，不是一段录好的动画，也不是真人的脑电图。

- 如果页面一直显示“加载中”，等一下再刷新一次；还不行就换个浏览器试试。
- 顶栏从左到右：PLAY（暂停/继续）、CONNECT（只看选中脑区的主要连接）、
  RESET（恢复默认）、HEAD EEG、EEG 分析、DIPOLE LAB、细胞实验、
  刺激实验、对照实验、模型信息。

## 2. 触碰：点一下大脑

**怎么做：** 用鼠标点一下大脑上的任意一个脑区。

**你会看到什么：** 被点的脑区亮起来，波形图上出现一个鼓包，
然后慢慢回到原来的样子。旁边还会显示这次响应传到了哪些脑区。

**这说明什么：** 只说明一件事——在这个简化模型里，点一下这里，
活动会这样传开。**不能说明：** 真人的这个脑区被碰到时会这样反应；
也不能说明这个脑区是管什么功能的。连接数据本身是演示用的混合数据
（一部分来自猴子实验、一部分来自人类扫描数据拼起来的），不是你的、
也不是某个真人的连接。

**如果点完大脑一直亮着不恢复：** 这不是卡住了，是模型进入了一个
“高活动稳定状态”（就像开关被拨到了另一档）。点横幅上的
「恢复到按住前」或 RESET 就能回来。

## 3. 刺激：按住、调滑杆

**按住：** 按住一个脑区不松手，等于持续给它输入。按住的时候如果出现
琥珀色横幅，是在提醒你“快到锁定的边了”，松开就停。

**四个滑杆（屏幕下方 PARAMETERS）：**

| 滑杆 | 调大 / 调小会怎样 |
|---|---|
| STIMULUS（刺激强度） | 点一下的力度变大 / 变小 |
| DURATION（持续时间） | 一次刺激变长 / 变短 |
| EXC / INH（兴奋 / 抑制） | 脑区之间“踩油门还是踩刹车”的比例 |
| CONNECTIVITY（连接强度） | 脑区之间互相影响的强弱 |

每个滑杆都能双击恢复默认值。调完再点一次脑区，对比两次的波形——
这就是这个工具最核心的玩法：**改一个东西，看结果怎么变。**

**这不能说明什么：** 滑杆上的数字是模型内部的单位，不是伏特、
不是毫安、不是真实刺激设备的档位。不要拿它去推断真实的脑刺激
（比如经颅电刺激）会发生什么。

## 4. 看 EEG：HEAD EEG 与 EEG 分析

**HEAD EEG：** 点开后能看到一个球形的“头”、一个可以拖动的电流源
和一圈电极。拖动电流源，电极上的波形会跟着变。
这个“头”是一个四层同心球的近似（脑 / 脑脊液 / 颅骨 / 头皮），
不是真实人头的形状，电极位置是标准方向投影到球面上的，
不能当成真人头上的电极位置。

**DIPOLE LAB：** 更简单的物理基线——均匀无限大导体里的一个偶极子，
12 个示意传感器。用来理解“有边界和没边界差别有多大”，
它本身不是脑电。

**EEG 分析：** 真正的实验台。点「运行实验」，会生成一份多导 EEG
记录（250 Hz），然后可以在五个 tab 里看：

- **EEG**：多导波形、换参考（平均 / 无限远 / 某个电极）、加噪声；
- **频谱**：这份信号里各个频段（delta / theta / alpha / beta / gamma）
  各占多少，有没有 alpha 峰；
- **ERP**：重复刺激很多次再平均，看刺激后几百毫秒有没有稳定的反应；
- **时频**：某个频率的能量在刺激前后怎么随时间变化；
- **地形 / 源定位**：头皮上哪里电位高、反推源大概在哪里。

**这不能说明什么：** 这里的 ERP 峰值只有 0.174 微伏，
而真实人的 P300 有 8.89 微伏——**差了 51 倍**。也就是说，
你在这里看到的“P300 样子”是对的（300–500 毫秒里有个鼓包，
靶刺激比标准刺激大 8 倍），但**大小完全不对**，不能拿这个数字去
和真实脑电报告上的数字比较。同样，这里的静息脑电几乎是“安静”的
（没有背景起伏），而真实人闭眼静息时脑电一直在起伏
（基线约 6 微伏）。源定位也一样：深部的源定位误差能到几十毫米，
浅部的才准——不要把定位结果当成源真的在那里。

## 5. 换模式：背景活动三档

在波形图附近可以切背景活动：

- **安静**：没有背景输入，最干净，适合看单次点击的响应；
- **自发**（默认）：每个脑区持续收到一点随机背景输入，看起来“有生命感”；
- **振荡**：外加一个 10 Hz 的正弦驱动——注意，这是**人为加进去的**
  外部信号，不是模型自己长出来的节律。

另外，模型自己确实有一个约 11 Hz 的自发节律（在 EEG 分析的频谱 tab
里选 Alpha 探索能看到），频率和真实 alpha 差不多（真实约 10 Hz），
但它占的功率比例是 99.8%，真实人只有约 30%——因为模型里没有
真实大脑那种宽带背景噪声。频率对得上，比例对不上。

## 6. 跑一个场景：从头到尾试一次（约 5 分钟）

1. 打开页面，等大脑加载出来，点一下左侧的一个脑区，看波形鼓包。
2. 把 CONNECTIVITY 滑杆从 0.35 调到 0.15，再点同一个脑区——
   响应传开的范围变小了。这就是“连接强度决定传播”。
3. 点「EEG 分析」→「运行实验」，等记录生成；切到「频谱」tab，
   看 alpha 峰在哪里；再切到「ERP」tab，看 oddball 和 standard
   两条曲线在 300–500 毫秒里差多少。
4. 点「细胞实验」，选 Hodgkin–Huxley，给神经元加一点电流，
   看它怎么放电（动作电位）。再选多房室，看树突上的信号怎么衰减。
5. 点「刺激实验」，先看 TES（约 0.79 V/m）和 TMS（约 85 V/m）
   在同一个目标处的电场差多少——差约 107 倍，这是两类刺激
   真实的量级关系。
6. 点「对照实验」，跑一次双脑 A/B：只改一个参数，看两边差多少；
   再试时间机器：暂停、单步、回到 1 秒前、换一个参数分叉。

每一步如果不知道某个数字是什么意思，点顶栏的「模型信息」，
里面写了数据来源、模型假设和许可说明。

## 7. 常见误解（一句话版）

- “波形这么小，是不是我的大脑有问题？”——不是。这不是你的脑电，
  是模型的演示输出，幅度本来就比真实小 51 倍。
- “定位说源在这里，就是这里在放电吗？”——不一定。深部源的定位
  误差能到几十毫米，峰值位置不可全信。
- “我调大刺激，真实脑刺激也会这样吗？”——不能这样推。模型里的
  刺激强度、电场到神经响应的增益都没有经过人体数据校准。
- “这个能用来看病、训练大脑吗？”——不能。它是教学仿真，
  不做诊断、不做治疗、不做任何健康判断。
- “图上的大脑是真人的吗？”——不是。连接数据是演示用混合数据，
  皮层网格是示例数据；真实 MRI 模板（fsaverage）只支持本地导入，
  不在公开网站上。
