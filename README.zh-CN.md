# BrainRun

[English README](README.md) · [打开网页](https://abwoo.github.io/brainrun/)

BrainRun 是可以直接在浏览器里操作的物理与神经动力学仿真工作台。首页以模型为主：移动电流源、调整参数，直接观察计算结果。整个界面提供中文和英文切换。

## 从物理模型开始

首页默认显示“电流与测量”，不会自动运行实验，也不会弹出预设面板遮挡模型。

1. 拖动橙色电流源，或使用三个位置滑杆。
2. 拖动箭头连续转向，调整带正负号的源强度，或反转极性。
3. 点击头皮电极，观察电位数字、头皮分布和波形。颜色使用固定微伏色标，显示来自同一份正向计算。
4. 在更多设置里按需使用第二源、给定电流脉冲、沿头皮移动电极或切换颅骨电导率。位置变化会更新对应矩阵行，电导率变化会加载重新计算的模型。
5. 在“头部模型”中选择真实模板 BEM，配套几何与矩阵会自动加载，无需准备文件。
6. 如需比较有限元计算，在“更多设置与模型说明 → 颅骨电导率”选择“四层球形 FEM”。电导率实际进入四面体方程；源限制在已求解的 ±16 mm 立方体内。它不是 MRI 解剖 FEM。
7. 打开“信号分析”，继续分析刚才的源。模型、电极、参考、源历史与观察时刻随记录和导出一起保留。

“脑区与传播”现会显示 Worker 的真实模型时间、所选 E/I 值，以及进行中和待执行的输入。稳定响应、暂停和模型时间不更新分别提示。反复强刺激可能使双稳态模型进入高活动状态；“恢复刺激前”会明确恢复完整检查点，重叠刺激不会用已受驱动的状态覆盖它。“使用轻输入设置”只把输入改为 0.5、20 ms，不自动刺激。曲线覆盖 0–1 活动范围，回退时清除旧运行轨迹。响应脑区数是最近一次刺激的 2 秒峰值汇总，不是实时活动仪表。

切换到“脑区与传播”，可以选择脑区、调整刺激强度与持续时间，再主动施加输入。点选位置和旋转视角本身不会施加刺激。三维大脑与活动曲线读取同一份后台求解器快照。

“恢复默认”用于回到已知配置。切换语言只改变显示，不重置参数和记录。

FEM 使用 30,745 个节点、174,080 个四面体，以及电流守恒的 2 mm 源／汇对基函数。头皮分布、移动电极、手动与原生 EEG、逆解和闭环投影使用同一 FEM 算子。未重参考值的数值基准为头皮面积均值为零；平均／电极参考的电位差不受该加性基准影响。导出保留数值身份与验证范围。详见[有限元方法与局限](docs/spherical-fem.md)。

## 高级功能

全脑 A/B 从同一完整状态分叉，保留原生 1 ms 轨迹、共同来源和可恢复的末状态；任一分支可继续进入 EEG 分析。JR 柱对照仍明确作为独立教学实验。

信号分析、单个神经元、刺激电场、对照与回放、脑区坐标和模型说明集中在“高级实验”。辅助预设位于独立页面，由用户明确选择运行，不遮挡首页模型。

下拉框统一使用原生可访问的 Dropdown；范围滑杆与数字输入使用共享控件。语言切换覆盖界面文案，计算中的通道名称、事件代码、数组与导出字段保持稳定。

如需使用 EEG 闭环，先在首页选择球形或模板 BEM 的电流源，再在“脑区与传播”中选择脑区，然后打开“对照与回放”。闭环测量选择“所选头部模型 EEG”。启动时会冻结对应的导体、源方向、电极和参考方式，界面会显示实际测量来源。“停止并分析反馈 EEG”会打开实际保留的因果滤波窗口。神经活动到偶极矩的映射仍是未经人体校准的显式假设，不代表演示网络已经完成解剖配准。

全导联连续 EEG：先在首页选择头部模型、主源和电极，并在“脑区与传播”中选择脑区；进入“信号分析”，选择 250 或 500 Hz，再点击“记录主物理源的神经驱动 EEG”。记录使用所选球形/BEM 几何与参考，由原生 E/I 驱动主源偶极矩，基线取当前保留积分记录的首个采样。手动源强度、脉冲和第二源不参与此驱动。波形、地形、逆解和导出读取同一冻结算子；A/B 在分叉前冻结测量几何。

## 前端与计算的连接

- 位置、方向与源强度通过 MNE 四层球形正向模型得到微伏电位。
- 脑区输入经 SimClient 和 Worker 进入 Rust/WASM Wilson–Cowan 求解器。
- 三维活动与曲线读取模型快照；事件采用求解器时钟和确认信息。
- 脑电记录、事件与试次保留运行来源；恢复快照会建立新的运行沿袭。

公开网页的计算在浏览器内完成，不依赖另外部署的数值计算接口。模型资产由 GitHub 构建流程生成。

## 模型的适用范围

本产品用于教学仿真，不是个体人脑的测量或预测。球形头模型不是个体 MRI/BEM；演示连接组不是受试者的个体连接网络，且没有与头部导体模型完成解剖配准。神经源到偶极矩的增益没有人体校准，幅度与逆解深度偏置的局限仍保留。主网络按每 1 ms 积分状态记录，经抗混叠滤波产生 250/500 Hz EEG，不依赖显示帧率；旧版快照派生实验受原始信息带宽限制。中心 FIR 是离线零相位处理，两端各舍弃 64 ms，不代表实时因果滤波。模板 BEM 使用平均解剖与已求解的皮层点，不是个体 MRI。直播闭环的特征窗口、周期、延迟和冷却使用 Worker 模型时钟，控制状态与待执行输入纳入快照。
